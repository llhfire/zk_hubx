# 线索管理业务流程图

> 本文与《PRD-线索管理模块-工程开发指导》配套使用，流程图使用 Mermaid 编写，可在支持 Mermaid 的 Markdown 工具中直接渲染。

## 1. 线索主业务流程

```mermaid
flowchart TB
    A[线索进入公海] --> B{线索是否有效}
    B -- 否 --> Z[标记为垃圾线索]
    B -- 是 --> C[认领或分配]
    C --> D[进入我的线索]
    D --> E[补充基础信息并持续跟进]
    E --> F{是否需要报价}

    F -- 是 --> G[新增报价]
    G --> H[报价配置与汇总]
    H --> I[完善报价资料并保存报价记录]
    I --> J{技术评估文件和报价单是否齐全}
    J -- 否 --> K[上传缺失文件]
    K --> J
    J -- 是 --> L[提交总经理审批]
    L --> M{审批结果}
    M -- 拒绝 --> N[编辑报价并生成新报价版本]
    N --> H
    M -- 通过 --> O[可作为合同创建参考]

    F -- 否 --> P[创建合同]
    O --> P
    P --> Q[维护合同版本]
    Q --> R[提交总经理审批]
    R --> S{审批结果}
    S -- 拒绝 --> T[编辑合同并生成新合同版本]
    T --> Q
    S -- 通过 --> U[上传合同归档]
    U --> V[显示合同信息与回款发票]
    V --> W[登记回款与开票]
    W --> X[线索成交并进入项目详情]
```

关键规则：

- 报价是可选流程；没有审批通过报价时，仍可直接创建合同。
- 编辑报价或合同均不覆盖原记录，必须生成新版本。
- 合同审批通过前，不显示线索详情中的“合同信息”和“回款与发票”Tab。

## 2. 报价记录与审批流程

```mermaid
flowchart LR
    A[新增报价或编辑最新报价] --> B[前端配置]
    B --> C[后端配置]
    C --> D[其他岗位]
    D --> E[出差驻场]
    E --> F[其他成本]
    F --> G[报价汇总]
    G --> H[完善报价资料]
    H --> I[保存报价记录]
    I --> J[生成报价汇总图片]

    J --> K{技术评估文件是否存在}
    K -- 否 --> K1[显示上传技术评估文件]
    K1 --> K
    K -- 是 --> L{报价单是否存在}
    L -- 否 --> L1[显示上传报价单]
    L1 --> L
    L -- 是 --> M[显示提交审批]
    M --> N[总经理审批中]
    N --> O{审批决定}
    O -- 审批同意 --> P[报价已审核]
    O -- 审批拒绝 --> Q[报价已驳回]
    Q --> R[基于最新报价编辑]
    R --> B
```

报价记录展示规则：

1. 按创建时间倒序，最新记录置顶，默认收起详情。
2. 只有最新记录可编辑或提交审批；历史记录仅查看。
3. 审批中显示“审批同意、审批拒绝”，两种操作均必须填写审批意见。
4. 报价详情展示预计周期、技术评估人、报价说明、报价汇总图片、技术评估文件、报价单和审批记录。

## 3. 合同版本、归档与回款流程

```mermaid
flowchart TB
    A{线索下是否已有合同} -- 否 --> B[合同记录显示创建合同]
    B --> C[新建合同并带入线索信息]
    A -- 是 --> D[展示合同历史记录]
    C --> D

    D --> E[最新合同版本]
    E --> F{是否修改合同}
    F -- 是 --> G[编辑合同]
    G --> H[填写修改说明]
    H --> I[生成新的合同版本和附件]
    I --> E
    F -- 否 --> J[提交审批]
    E --> J

    J --> K[总经理审批中]
    K --> L{审批决定}
    L -- 审批拒绝 --> G
    L -- 审批同意 --> M[审批通过，形成终稿]
    M --> N[显示合同归档区域]
    N --> O[上传归档合同文件]
    O --> P[合同信息Tab可见]
    P --> Q[回款与发票Tab可见]

    Q --> R[生成或读取回款计划]
    R --> S{是否拆分期次}
    S -- 是 --> T[保留父期并新增多个子期]
    T --> U[维护子期回款和开票]
    S -- 否 --> U
    U --> V[登记回款记录]
    U --> W[登记开票记录]
    V --> X[自动计算回款状态]
    W --> Y[自动计算开票状态]
```

合同与回款规则：

- 一个线索仅关联一个合同，合同可有多个版本。
- 仅最新合同版本可编辑、提交审批；历史版本不显示编辑和提交审批。
- 合同审批中创建新版本时，当前审批自动撤回，新版本成为最新版本。
- 拆分后保留父期，子期以“第 N 期-1 / 第 N 期-2”层级展示；子期金额合计必须等于父期应回款金额。
- 回款、开票状态由该期明细累计金额自动计算，不允许手工改状态。

## 4. 文件归集与资料 Tab 流程

```mermaid
flowchart LR
    A[跟进附件] --> H[关联到线索]
    B[报价文件和报价汇总图片] --> H
    C[合同版本附件和归档文件] --> H
    D[回款凭证和发票文件] --> H
    E[出差和报销附件] --> H
    F[演示上传文件] --> H
    G[手工上传资料] --> H

    H --> I[资料Tab统一文件库]
    I --> J{是否为同一文件}
    J -- 是 --> K[合并为一条资料记录]
    J -- 否 --> L[新增资料记录]
    K --> M[显示全部来源标签]
    L --> M
    M --> N[支持筛选、预览和下载]
```

文件规则：

1. 资料 Tab 是该线索全部文件的权威入口；演示 Tab 只展示演示记录和网址。
2. 同一文件被多个业务模块引用时，资料 Tab 只展示一条，并显示多个来源标签。
3. 文件需保留来源模块、来源业务记录、上传人、上传时间，供资料列表筛选和追溯。
4. 删除文件引用时仅删除当前业务引用；没有其他引用时才删除实际文件。

## 5. 页面跳转流程

```mermaid
flowchart LR
    A[公海线索/我的线索/垃圾线索] --> B[线索详情]
    B --> C[创建合同]
    C --> D[新建合同页]
    D --> E[编辑合同页]
    E --> F[合同预览与提交]
    F --> G[返回线索详情的合同记录Tab]

    H[合同列表] --> I[合同详情]
    I --> J[返回合同列表]

    K[已成交线索] --> L[项目详情]
    L --> M[项目的报价、合同记录、回款与发票]
```

跳转规则：

- 从线索详情进入合同新建、编辑或查看流程后，返回时必须回到原线索详情及原 Tab。
- 从合同列表进入合同详情时，返回合同列表，不能跳转线索详情。
- 已成交线索的名称和详情入口均跳转项目详情。
