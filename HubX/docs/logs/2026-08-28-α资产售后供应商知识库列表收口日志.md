# α 资产、售后、供应商与知识库列表收口日志

## 本轮范围

仅调整 α 原型页面，不修改 β Web、API 或数据协议。以共享 UI 组件库和“我的线索列表”的信息节奏为基准，收口 `/assets`、`/maintenance`、`/suppliers`、`/knowledge` 四个一级入口。

## 完成内容

- 四页统一接入 `PageShell`、`PageHeader` 和 `ProcessMetricGrid`，页面标题固定为 20px，主操作统一放在页头右侧。
- 资产管理新增关键词检索、类型与状态组合筛选、结果计数、无结果空态和清除入口；修复类型页签与筛选条件无法同时生效的问题。
- 售后运维的维护期、客户工单、续费合同和费用记录共用实时检索；主操作随页签切换，客户工单显示“新建工单”，费用页签显示“新增费用”。
- 供应商管理新增联系人、电话、邮箱、技能关键词检索和企业/个人筛选；卡片在中窄屏自动调整为双列或单列。
- 知识库保留组织树、分类、上传、预览和权限流程，增加全局摘要、筛选结果、重置入口；窄屏下组织树与文档列表改为单列。
- 四页表格统一限定横向滚动范围，图标操作补充无障碍名称。

## 验证结果

- 模型单测：`supportDomainListModel.test.ts`，3/3 通过；全量 Vitest 为 86 个文件、980 项测试全部通过。
- α 构建：`npm run build` 通过，仅保留仓库既有的大 chunk 与 Gantt 注释提示。
- 浏览器验收：四页初始指标、实时筛选、结果计数、无结果空态和清除筛选均通过。
- 响应式验收：1200px 与 760px 下均无页面级横向溢出；供应商卡片和知识库组织框架按断点正确换列。
