# 2026-08-28 α 版报价流程收口日志

## 完成范围

本次仅收口 `apps/prototype` 与 `packages/ui` 中的 α 版报价流程，覆盖计划 4.1–4.8：

- 统一为十状态报价状态机，补齐回退、新版本、删除、改指及线索终止冻结规则。
- 报价编号统一为 `QT-YYYY-N`；审批人在提交时读取配置并固化快照。
- 统一岗位日成本、利润率、工作日工期、付款期次、含税人民币及专票口径。
- 新建主报价时选择数据流转或文件流转，创建后不可切换。
- 文件流转贯通清单 Excel、评估文件、在线报价文档、盖章定稿与扫描件。
- 客户报价单按“封面—项目信息—公司介绍—功能清单—费用汇总—自费项目—签章”输出，不展示岗位成本、日单价和利润率。
- 主合同批准后可创建补充报价；补充报价确认后预填补充合同，支持负数减额。
- 主报价与补充报价均可向合同向导传递金额、付款计划、工期、质保及发票类型。
