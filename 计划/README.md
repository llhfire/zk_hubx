# 计划/

施工用的计划稿。业务叙事在 `文档/`，这里写「做什么、按什么顺序、刻意不做」。

| 子目录 | 用途 |
|--------|------|
| [`当前/`](当前/) | **正在执行或刚拍板的实现计划。** 新开计划放这里。报价阶段 4：`quote-flow-prd-implementation.md`。 |
| [`历史/`](历史/) | 已完成或过期的计划。`历史/superpowers/` 是早期 specs/plans。 |
| [`会话/`](会话/) | 单次会话的 PLAN.md（可不进 git）。 |

新计划命名：`主题-简短说明.md`。改计划后同步功能看板、架构图、对应 PRD。
