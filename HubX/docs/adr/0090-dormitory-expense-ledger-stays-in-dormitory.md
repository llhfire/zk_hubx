# 0090 宿舍费用账本留在宿舍模块，运营费用只读引用

运营费用 PRD 有「一条费用只有一个写入方」原则，科目树也含宿舍租金，直觉做法是把租金/水电挪进运营费用台账录。选择相反：宿舍费用（租金/水电/燃气/网络）继续在差旅-宿舍子模块的 `DormitoryExpense`/`UtilityPayment` 台账记账，它是这类费用的唯一写入方；运营费用台账对宿舍租金科目只读引用月度合计，不重复记。理由：宿舍费用与楼/房/床位实物和按房间/按人分摊强耦合，离开实物台账记账会丢失分摊依据；财务看运营大盘只需引用合计。代价：公司租金账的明细在差旅模块维护，财务跨模块看数；用月度汇总视图弥补。
