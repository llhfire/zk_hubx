# 线索详情页 360° 重构计划

> 基于 `research/线索详情页重构.md` + 高保真交互原型 HTML 进行重构
> 现有 LeadDetail.tsx (2153行) 全面重构为 360° 全景工作台

## 一、核心决策

| 维度 | 决策 |
|---|---|
| 布局 | 左右分栏 50:50 |
| 控制台头部 | 统一行动栏 + 按 clueType 隐藏不适用操作 |
| 生命周期 | 6 步步骤条（接入→建联→调研→签约→交付→终验） |
| 指标胶囊 | 6 维全部做（负责人/对接人/总标的/回款/PM/工期） |
| 左侧 Tab | 3 个（基础信息/合同信息/回款与发票） |
| 左侧下方 | 独立板块：项目交付执行 |
| 右侧跟进上方 | 独立板块：售前聊天群分析 |
| 右侧 Tab | 7 个（跟进/报价/合同记录/演示/资料/出差/报销） |
| 档案卡 | 提取到顶部常驻显示 |

## 三、控制台头部

### 项目元数据

- 线索编号（一键复制）
- 线索名称
- 状态标签（销售漏斗状态）
- 客户等级标签（S/A/B/C）
- 对接主体标签
- 来源标签

### 6 步生命周期步骤条

| 步骤 | 对应销售状态 | 显示 |
|---|---|---|
| ① 接入录入 | 未联系 | 已完成/当前/未到 |
| ② 初步建联 | 未接通 + 初步沟通 | 已完成/当前/未到 |
| ③ 需求调研 | 需求调研 | 已完成/当前/未到 |
| ④ 主合同签署 | 方案报价 + 合同洽谈 | 已完成/当前/未到 |
| ⑤ 项目交付中 | 已签单 | 已完成/当前/未到 + 进度% |
| ⑥ 终验结项 | 已签单（项目完成） | 已完成/当前/未到 |

### 6 维指标胶囊

| 胶囊 | 数据源 | 样式 |
|---|---|---|
| 负责人/归属 | owner + daysHeld + trashCount | 蓝色 |
| 客户对接人 | contact + phone + wechat（一键复制/外呼） | 灰色 |
| 有效总标的额 | 主合同 + 补充合同合计 | 绿色 |
| 总回款进度 | 已到账金额 + 百分比 | 绿色 |
| 内嵌交付项目 PM | 关联项目 + PM 名称（点击跳转） | 蓝色 |
| 交付进度/工期 | 项目进度 + 剩余天数 | 橙色/红色（逾期） |

### 全局行动栏

| 操作 | 显示条件 | 样式 |
|---|---|---|
| + 登记跟进 | 始终显示 | primary |
| + 新建补充报价 | clueType=assigned | default |
| 编辑线索 | 始终显示 | default |
| 转移给他人 | clueType=assigned | default |
| 扔回公海 | clueType=assigned（第3次显示熔断提示） | warning |
| 标记垃圾 | clueType != trash | danger |
| 删除 | 始终显示 | danger |

## 五、左侧 3 个 Tab

### Tab 1：基础信息

两列字段布局：
- 对接主体、线索意向、线索状态、客户类型(S/A/B/C)
- 客户预算、客户主体、售前群名称、原型图链接
- 威客任务号、推广关键词、意向标签、客户信息备注
- 客户主体工商档案（主体全称/通讯地址/公司电话/邮箱）

### Tab 2：合同信息

- 正式主合同卡片（编号/标的额/签约主体/状态/签约日期/附件）
- 补充合同列表（编号/描述/变更金额/对应报价/状态/附件）

### Tab 3：回款与发票

- 汇总指标（有效总标的/已到账/待回款/已开票）
- 全期次明细台账（期次/金额/比例/触发条件/计划日/到账状态/开票状态）

## 六、左侧下方：项目交付执行（独立板块）

- 交付概况状态横幅（项目编号/业务线/健康度/PM/工期/进度条）
- 5 步里程碑推进（立项→UI确认→核心开发→提测→终验）
- 任务与缺陷看板（开发任务列表 + Bug Tracker）
- 工时投入与团队台账（预算/累计/岗位分布）

## 七、右侧跟进 Tab 上方：售前聊天群分析（独立板块）

- 售前群名称 + 群类型图标
- AI 摘要分析结果
- 最近聊天记录摘要
