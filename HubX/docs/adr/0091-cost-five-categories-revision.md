# 0091 成本五类修订为人工/差旅/推广/商务/第三方（修订 0086 分类部分）

ADR-0086 锁定的成本五类是「人力/商务（含差旅与出差补贴）/运营（分摊）/第三方/硬件」。2026-08-21 业务单详情重构 grill 时，用户拍板以新版高保真原型的五类为准：**人工 / 差旅 / 推广 / 商务 / 第三方**。理由：差旅独立成类后与差旅管理模块（ADR-0089 出差必挂项目/线索、费用归集随对象分流）直接对齐，不再需要在商务里做二次拆解；推广（获客成本分摊）独立后，广告投放「直接归集至成交业务单」的口径有了显式科目。原两类的去向：**运营分摊（项目工天 × 时薪公摊率）整体归推广类**，ADR-0081 的时薪公摊率接缝改挂在推广侧、常量不变；**硬件采购归第三方类**。同时确认：commercialCap 商务上限只管商务类（宴请招待），差旅类不受其管控（差旅有自己的硬软标准线）。代价：calc.ts 成本结构派生、mockCostItems 分类字段、健康卡与成本归集 Tab 全部按新五类改；术语表（模块 CONTEXT.md）同步修订。ADR-0086 的其余部分（派生化、三通道写入、轻实体）不变。
