# 02 · 设计系统结构

代码位置：`HubX/packages/ui/src/design-system/`
唯一导出入口：`@/design-system`（vite alias → `packages/ui/src`）

---

## 一、六层分类

按**抽象层级 + 职责**分，**禁止按业务域分**（按域分会让每个域长出自己的表格和工具栏）。

| 目录 | 放什么 | 判定标准 |
|---|---|---|
| `primitives/` | 只表达一个值或一个语义，无业务状态 | 换个业务域还用不用得上 |
| `layout/` | 页面结构、区块、页头 | 它决定「页面长什么样」 |
| `data-display/` | 表格、指标、字段区、空态、进度、文件行 | 它只负责把数据摆出来 |
| `forms/` | 筛选、字段网格/分组、上传、富文本 | 它是输入 |
| `feedback/` | 确认、提醒、异步三态 | 它是对一个动作或状态的反应 |
| `business/` | 跨页面复用的业务语义 | 只有本域语义的不要放这里 |

## 三、Token 体系（`tokens.css`）

**必须挂在 `body` 上，不能挂 `:root`。** Arco 把 `--primary-1` / `--color-fill-2` 这些色阶
定义在 `body`；CSS 自定义属性里的 `var()` 在**声明所在元素**解析，挂 `:root` 时这组变量
对 `html` 不可见，整组 `--ds-tone-*` 变成 guaranteed-invalid —— 背景退化成透明、
描边退回 `currentColor`，**而且不报任何错**。同理 `components.css` / `foundation.css`
必须 `@import './tokens.css'`。

本次新增 **65 个 token**：

| 组 | 数量 | 用途 |
|---|---|---|
| `--ds-tone-{purple,cyan,pink,gold}-{bg,fg,border}` | 12 | 补齐 9 tone 中的分类色 |
| `--ds-text-{micro,caption,dense}` | 3 | 10 / 11 / 13px，补上产品字号阶梯的密集档 |
| `--ds-shadow-{subtle,card,up,panel,raised,overlay,viewer,viewer-strong}` | 8 | 阴影唯一来源 |
| `--ds-icon-{lg,hero}` | 2 | 图标尺寸 |
| `--ds-radius-pill` | 1 | 胶囊圆角 |
| `--ds-doc-*` | ~24 | 报价单 A4 复刻专用（纸张、横线、墨色、品牌色） |
| `--ds-viewer-*` | ~16 | 文件阅读器深色外壳配色 |

## 四、CSS 落点

| 文件 | 放什么 | 页面能否新增 |
|---|---|---|
| `tokens.css` | 所有设计变量 | 否 |
| `components.css` | 设计系统组件自身样式（本次 +60 条规则） | 否 |
| `foundation.css` | 页面骨架（shell / header / filter-bar / split / metric-grid） | 否 |
| 页面自己的 `.css` | **只允许布局**（本次只新增 `/ui-library` 演示区的布局类） | 仅布局 |

本次 `components.css` 新增的规则块：`.hubx-approval-flow*`（20 条）、
`.hubx-progress-circle*`（环形进度）、`.hubx-progress--{small,large}`、
`.hubx-status-tag--interactive` + `__close`、`.hubx-alert-banner--{compact,success}` + `__title`、
`.hubx-grade-tag--{s,a,b,c}`、`.hubx-metric-card__{head,icon,badge}`、
`.hubx-data-table__toolbar-{start,end}`、`.hubx-section-card--{small,borderless}`。
