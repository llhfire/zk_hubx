# 公司运营成本费用管理模块

## 模块定位

作为人资行政部门，需要把公司运营的各项成本费用输入到系统中，作为计算公司运营成本、项目成本的基础数据。

## 核心需求

### 1. 费用分类管理

费用分类支持在系统中维护（可配置的字典管理），默认分类如下：

| 一级分类 | 二级分类 |
|---------|----------|
| **人力成本** | 基本工资、绩效工资、社保公积金、商业保险、奖金提成、年终奖、餐补、交通补贴、通讯补贴、住房补贴、高温补贴、加班费、招聘费用、培训费用、差旅补贴、离职补偿 |
| **办公成本** | 办公室租金、物业管理费、水电费、网络通讯费、电话费、办公用品、办公家具、设备折旧、设备租赁、服务器托管、宿舍租金、装修摊销、保洁服务、绿植租赁 |
| **差旅成本** | 市内交通、长途交通（机票/火车）、住宿费、出差补贴、餐饮费、车辆租金、油费、电费、过路费、停车费、车辆保养、车辆保险 |
| **福利成本** | 团建活动、节日福利、员工体检、下午茶/零食、文体活动、生日福利、婚丧礼金、子女教育补贴、健身补贴、团建旅游 |
| **商务成本** | 招待费、礼品费、佣金返点、渠道费、商务宴请 |
| **市场成本** | 市场推广费、展会费、广告费、品牌宣传、活动赞助、内容营销、线上推广、线下推广 |
| **第三方服务费** | 云服务、软件订阅、域名/SSL、短信服务、法务费用、审计费用、保险费用、外包服务、咨询服务、代理服务 |
| **财务成本** | 坏账损失、利息支出、汇兑损失、手续费、资产减值 |
| **税费** | 增值税、所得税、印花税、城建税、教育费附加、其他税费 |
| **其他** | 杂项费用、临时支出、捐赠赞助、罚款支出 |

### 2. 费用发生频率

- **周期性费用** — 支持模板自动生成，设置一次模板，系统按周期自动生成费用记录
- **一次性费用** — 按实际账单发生，手动录入

### 3. 费用生效时间

- **模板金额调整** — 记录新金额的生效时间
- **费用追溯** — 支持补录或调整历史数据

### 4. 费用归属

费用支持归属到：
- **公司整体** — 如办公室租金、管理层工资
- **具体项目** — 如某项目的差旅费、外包费用
- **部门** — 如市场部的广告费

### 5. 数据来源

- **从报销单自动归集** — 员工报销通过后，自动计入对应费用
- **从工资单自动归集** — 工资发放后，自动计入人力成本
- **从合同自动归集** — 第三方服务合同到期付款后，自动计入费用
- **手动录入** — 所有费用都由财务人员手动输入

### 6. 审批流程

无需审批，财务人员直接操作。

### 7. 查询和报表

- **费用明细查询** — 按时间、分类、项目、部门等筛选
- **费用汇总报表** — 按月/季度/年汇总各类费用
- **费用趋势分析** — 费用变化趋势图
- **项目成本报表** — 某个项目的全部费用明细
- **部门成本报表** — 某个部门的全部费用明细
- **费用预算对比** — 实际费用 vs 预算（展示历史数据对比）

### 8. 预算管理

不设计预算管理功能。

### 9. 数据导入

支持从 Excel 导入历史费用数据。

### 10. 多币种

仅涉及人民币，不支持多币种。

### 11. 数据量预估

中型规模，每年 500-2000 条费用记录。

### 12. 模块集成

需要与以下模块集成：
- **报销模块** — 报销单通过后自动归集费用
- **工资模块** — 工资发放后自动归集人力成本
- **合同模块** — 第三方合同付款后自动归集费用
- **项目模块** — 项目费用归属和成本计算

## 术语表

| 术语 | 定义 |
|------|------|
| 费用分类 | 费用的分类体系，支持一级分类和二级分类，可在系统中维护 |
| 费用模板 | 周期性费用的配置模板，系统按模板自动生成费用记录 |
| 费用归属 | 费用关联的对象，可以是公司整体、具体项目或部门 |
| 费用追溯 | 补录或调整历史费用数据的功能 |
| 生效时间 | 费用模板金额调整后，新金额开始生效的时间 |
