# 报价系统开发会话日志 - 2026-08-15

## 本次会话核心主题

报价系统四个工作台全面重构，引入「端 + 平台」架构，工作台三从网页自动化改为真实报价配置。

## 一、架构重构：端 + 平台

### 背景
原工作台三包含前端配置、后端配置、基础岗位配置等步骤，但这些数据应该在更早阶段确定。经 grilling 确认职责边界：

| 数据 | 归属阶段 |
|------|---------|
| 端 + 平台选型 | 工作台一（功能清单） |
| 基础岗位配置 | 工作台二（技术评估） |
| 销售增项岗位 | 工作台三（报价配置） |
| 出差/驻场/其他成本 | 工作台三（报价配置） |

### 新数据模型
```typescript
interface EndpointConfig {
  id: string;
  name: string;           // 端名称（"用户端"、"管理后台"）
  platforms: string[];    // 适配平台ID列表
}

interface FeatureModule {
  id: string;
  name: string;
  sort: number;
  subFeatures: FeatureSubFeature[];
  endpointId: string;     // 关联端
}

// 出差驻场改为多地点数组
interface TravelOnsiteConfig {
  enableTravel: boolean;
  travelSubtotal: number;
  enableOnsite: boolean;
  onsiteSubtotal: number;
  travelDetails: TravelDetail[];  // 多地点
  onsiteDetails: OnsiteDetail[];  // 多地点
}
```

## 二、工作台一（功能清单）改造

### 端列合并（核心难点）
- Arco Table 不支持 rowspan，改用原生 HTML table
- 端列 rowspan 合并，同端只显示一次端名称 + 平台 Tag 竖排
- 序号列每行独立

### 端配置
- 顶部"新增端"按钮：创建端 + 在清单末尾新增空模块
- 端名称可编辑（表格内联编辑）
- 平台多选通过 Popover 弹出
- "新增一级模块"下拉选择端
- "新增子功能"级联菜单（端→模块）

### 焦点定位
- 新增端 → 焦点到端名称输入框
- 新增模块 → 焦点到模块名称输入框
- 新增子功能 → 焦点到功能描述输入框

## 三、工作台二（人天评估）改造

### 端列显示
- 原生 table + rowspan 端列（只读）

### 键盘漫游（重写）
- WASD 带值漫游（W上/S下/A左/D右）
- 上下键调值（光标位置感知）：
  - 光标在小数位 → 增减 0.1
  - 光标在个位 → 增减 1
  - 光标在十位 → 增减 10
  - 光标在百位 → 增减 100
- 左右键移动光标

### 岗位管理
- 表头岗位列可删除（×按钮）
- 拖拽排序（⠿手柄）
- 新增岗位（预设 + 自定义）

### 底部浮动栏
- 定位按钮（级联菜单：端→模块→子功能，点击定位+高亮闪烁）
- 岗位统计（弹出表格：端+模块+人天+占比）
- 端统计（每个端独立按钮）

## 四、工作台三（报价配置）重构

### 功能清单与工时评估（合并表格）
- 端（rowspan）+ 模块（rowspan）+ 子功能
- 各岗位工时列（表头含岗位名 + 日均成本）
- 人天列 + 合计行

### 岗位日均成本
- 表头显示 ¥XX/天，点击可编辑
- 修改后重算总金额

### 销售增项岗位
- 岗位名称/人数/天数/日均单价/增项事由
- 增项小计

### 出差与驻场（多地点）
- 出差：可添加多个地点，每个地点独立配置
- 驻场：可添加多个地点
- 差旅合计/驻场合计

### 其他成本
- 添加费用项 + 其他合计

### 报价汇总
- 项目综述（项目名称/工期/人天/总价）
- 费用明细表格（费用项/金额/说明）

## 五、工作台四（审批盖章）重构
