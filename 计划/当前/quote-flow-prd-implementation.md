本计划把已拍板的报价域改造成可施工的阶段。阶段 3（已确认生成主合同、合同批准交付启动）已在库里，本计划是 **阶段 4：报价域按新词表与双来源收口**。只做 α（`packages/ui` + `apps/prototype`）；β 复合接口后置。

## 0. 对照：现网 vs 目标

| 现网 | 目标 |
|------|------|
| 13 态（含成交、已作废、已转派销售） | 草稿 → 待评估 → 待报价 → 待审核 → 待盖章 → 已盖章 → 已发出 → 已确认；已驳回 / 已废止；过期是已发出上的标记 |
| 会签写死黄奕/罗总/闵总 | 提交时拍「报价审批 / 补充报价审批」配置快照 |
| 校验硬拦 | 会签前数字只黄灯；步骤完成条件除外（空清单不能评估、主报价人天/总价须 > 0） |
| 仅数据流转工作台 | 创建时选定来源，此后不可改：数据流转 / 文件流转 |
| 客户件自拟 PDF | 按中科标准件；数据流转盖章定稿；文件流转在线编辑终稿 + 扫描件 |
| 补充协议挂在合同下填金额 | 补充报价 → 已确认 → 向导生成补充合同；「补充协议」对象废弃 |
| 成交 | 已确认；向导生成合同，不自动插入 |

## 1. 明确不做（本计划）

- β 成交/批准跨表事务接口
- 扣子生成功能清单
- 多币种、法定节假日日历、报价单独节假日
- 上浮比例倒推总价（已废，改为利润率统计项）
- 文件流转解析评估人天明细
- 自动废止报价或连锁作废合同
- 在客户件上印岗位成本 / 利润率

## 2. 阶段切分（按依赖，可串行；4.2 与 4.3 可并行）

### 4.1 状态机与词表（先做，后面全靠它）

- `QuoteStatus` 收到：`draft / pending_eval / pending_quote / auditing / rejected / pending_stamp / stamped / sent / confirmed / voided`。去掉 `feature_confirmed`、`eval_completed`、`assigned_sales`、`quote_summarized`、`deal`、`pending_followup`；`voided` 展示「已废止」。
- `deriveStage`：草稿=1，待评估=2，待报价/已驳回=3，其余=4。
- 动作补齐并改名：`mark_confirmed`（原 mark_deal）、撤回发出、退回盖章、退回改清单、退回技术重评。
- 过期：`sentAt + validDays`（默认 30，配置），不改状态。
- 单号：`QT-YYYY-序号`，主/补共用当年序列，每年从 1 计。
- 迁移 mock / HTTP 种子与 `quotationMutations` 合法迁移表；单测锁迁移。
- 阶段 3 按钮文案：成交 → 已确认；「生成主合同」保留。

**验收**：旧状态不再出现在 UI；撤回审批回待报价；已发出可回已盖章；未发出已盖章可回待盖章。

### 4.2 责任人、权限、通知、列表

- 创建：有报价权限的人可建；选来源、签约主体、技术评估人、销售。
- 默认：评估人 ← 配置；销售 ← 线索负责人否则配置兜底。
- 终态前可改指；线索改派不改报价销售。
- 打开范围：创建人、线索负责人、评估人、快照会签/盖章人、有报价权限的管理员。能打开就能看岗位成本和利润率。
- 列表：全部状态 + 待我处理 + 已发出上的过期标记。无「已完成」。
- 通知与待我处理同一套收件人算法。
- 线索当前已终止/垃圾：不能新建主报价、未终态主报价不能前进；恢复后解冻。补充报价只看主合同。
- 从未提交过评估的草稿可删；退回改清单的草稿不能删。

**验收**：改派线索后待办仍在原销售；终止线索无法送审主报价。

### 4.3 计价与作业字段

- 结构化付款期次（合计 100% 只黄灯）；质保年数默认 1；工期/评估工期为工作日（只跳周六日）；总价含税人民币；发票类型默认专票。
- 利润率 = (总价 − 增项 − 岗位成本) / (总价 − 增项)；增项不进；低于配置底线（默认 15%）黄灯。开发售价 ≤ 0 则利润率空。
- 岗位日成本：配置岗位价 + 兜底 600；模板可覆盖；本单可改。
- 报价模板：增项结构、岗位日成本默认、工期参考。不含清单/评估/利润率。
- 自费项目：公司默认清单预填，本单可改，不进总价。
- 主报价总价必须 > 0 才能送审；补充报价总价可为负。
- 文件流转表单是作业数据；编辑器改数字不回写；不一致黄灯。

**验收**：改岗位成本或总价后利润率重算；补充报价可录 −20000。

### 4.4 审批配置接线

- 业务类型：「报价审批」「补充报价审批」，默认模板三人并行会签 + 盖章节点。
- 提交时拍快照；撤回/驳回再提按当时配置重拍。
- Stage4 读快照，不再写死人名。
- 现成「业务负责人→财务」串行默认不要接到工作台，除非改过模板。

**验收**：改配置不影响已在待审核的单；新提交跟新配置。

### 4.5 文件流转（创建后不可改来源）

- 创建时报选数据流转 / 文件流转。
- 步骤 1：上传清单，按五列解析成两级清单；0 行不能提交评估。
- 步骤 2：评估文件 + 评估工期 + 总人天（备注可选）。不解析人天列。主报价总人天须 > 0。
- 步骤 3：报价工期、总金额、付款期次、有效期、增项（可 0 行）、可选利润率展示/质保。
- 在线文档：初稿 = 标准件 + 表单 + 已解析清单。必须保存过才能送审。盖章后只读。退回改清单作废终稿并按新清单重预填。
- 扫描件从待盖章起可传。

**验收**：文件流转无保存不能送审；退回改清单后须再保存。

### 4.6 客户报价单（两种来源同一版式）

- 按 `中科-微官网(基础版)-报价单.pdf`：封面（补单号）→ 整体报价 → 公司介绍 → 详细报价清单 → 自费项目 → 签章。
- 抬头/介绍/授权代表/电话/地址/电子章来自本单签约主体；盖章前可改主体（文件流转已存文档不自动改，须撤回后重存）。
- 数据流转：待报价/已驳回草稿水印预览；盖章生成无水印正式版并锁定。
- 补充报价同一版式，只印本单变更。
- 不印岗位成本、日单价、利润率。

**验收**：数据流转盖章后 PDF 无水印且不可再生成覆盖；文件流转下载电子终稿与扫描件。

### 4.7 补充报价 → 补充合同（替代补充协议）

- 主合同 `approvedAt` 之后才能建补充报价。
- 同一套四步 + 来源模式；会签走「补充报价审批」。
- 签约后可多份同时已确认，各对一份补充合同。
- 已确认后「生成补充合同」向导预填（金额=变更额，可负）。
- 合同详情「补充」改为补充报价/补充合同列表；停用「新建补充协议」填金额入口。
- 计入规则不变：补充合同归档且未作废才进有效标的额。

**验收**：批准前不能建补充报价；减额补充合同归档后标的减少。

### 4.8 与合同联动收口

- 已确认 + 无未作废对应合同 → 生成主/补充合同。
- 已生成未作废合同的已确认报价不能废止；先作废合同。
- 合同作废后同一已确认报价可再生成，不必废止报价。
- 预填：含税总额、付款期次、工作日推结束日、质保、发票类型、签约主体（向导可改）。

**验收**：作废合同后原报价可再点生成；未作废合同时废止报价被拒绝。
