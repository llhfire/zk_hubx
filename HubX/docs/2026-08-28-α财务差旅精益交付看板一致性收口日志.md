# α 财务、差旅与精益交付看板一致性收口日志

## 本轮范围

仅调整 α 原型页面，不修改 β Web、API 或数据协议。以共享 UI 组件库和线索页的信息节奏为基准，收口 `/finance/dashboard`、`/travel/dashboard`、`/financial-delivery/dashboard` 三个一级看板。

## 完成内容

- 三页统一接入 `PageShell`、`PageHeader` 和 `ProcessMetricGrid`，页面标题固定为 20px，移除空页头、重复内边距、彩色顶边和装饰性 KPI 图标。
- 财务看板按“合同统计 / 运营成本”动态显示四项核心指标；保留合同费用穿透、图表、筛选、费用录入、编辑和删除流程。
- 差旅看板的个人、部门、项目和费用分析均统一为四项指标；保留管理员/个人权限切换及人员、部门、项目、时间组合筛选。
- 精益交付将原有七张概览卡合并为业务单、风险、回款、利润四项全周期指标；保留健康度、敏感性模拟、风险列表和业务单穿透。
- 颜色只表达状态：成功用于到账与正利润，警告用于待收、待报销和风险预警，危险用于未结清与超标。

## 验证结果

- 全量 Vitest：86 个测试文件、980 项测试全部通过。
- α 构建：`npm run build` 通过，仅保留仓库既有的 Gantt 注释与大 chunk 提示。
- 浏览器验收：财务标签切换和费用录入弹窗、差旅标签与权限切换、精益交付主次操作均正常。
- 响应式验收：1200px 与 760px 下三页标题均为 20px，当前看板均显示四项核心 KPI，无页面级横向溢出，控制台无错误。
