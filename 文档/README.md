# 文档/

给人读的业务与产品资料。**不是代码。** 应用说明在 `HubX/docs/`。

| 子目录 | 放什么 |
|--------|--------|
| [`PRD/`](PRD/) | 各模块产品需求。报价以 `PRD/PRD-报价流程管理.md` 为准（v1.1，grill 后）。 |
| [`需求/`](需求/) | 原始需求池、录音整理、OA 需求、领域扩展等未收成 PRD 的输入。 |
| [`报价/`](报价/README.md) | 报价流程规范、工作台说明、客户报价单标准件。 |
| [`计划与进度/`](计划与进度/) | 演进史、进度对齐表、旧开发计划。**当前实现计划在仓库根 `计划/当前/`。** |
| [`会议/`](会议/) | 会议录音、纪要。 |
| [`手册/`](手册/) | 操作手册、SOP、岗位配置。 |
| [`线索管理/`](线索管理/) | 线索域补充说明（从代码里抽出的规则等）。 |
| [`归档/`](归档/) | 过期中间稿（如 PRD 的 analysis/formatted 副本），不要当现行需求。 |

领域用词以 `HubX/CONTEXT.md` 为准。报价硬决策在 `HubX/docs/adr/`。
