# α 出差与借款列表一致性收口日志

## 本轮范围

仅调整 α 原型，不修改 β Web、API 协议或生产链路。收口 `/travel/trips` 与 `/travel/loans` 两个差旅一级列表，并保留已有出差状态操作、借款审批、打款和详情抽屉。

## 完成内容

- 两页统一接入 `PageShell`、`PageHeader`、`ProcessMetricGrid` 与 `FilterBar`，页面标题统一为 20px，主操作移至页头。
- 出差申请补充申请总数、待审批、执行中和预计费用四项摘要；借款管理补充申请总数、待审批、待打款和未冲抵余额四项摘要。
- 筛选区统一展示结果数量，存在筛选条件时显示“重置筛选”；修复两页重置后仍按旧条件查询的状态闭包问题。
- 借款创建日期筛选由占位控件改为真实过滤，关键词、状态与日期可组合查询。
- 出差与借款表格图标操作补齐 Tooltip、统一按钮样式，并使用包含业务单号的无障碍名称；详情金额与状态改用主题语义色。
- 保留出差详情穿透、新建入口、借款详情抽屉及审批时间线，未执行会改变业务数据的审批、打款或状态推进操作。

## 验证结果

- 全量 Vitest：86 个测试文件、980 项测试全部通过。
- α 构建：`npm run build` 通过，仅保留仓库既有的 Gantt 注释与大 chunk 提示。
- 浏览器验收：两页关键词搜索与重置、出差详情穿透、借款日期筛选和详情抽屉均正常。
- 响应式验收：1200px 与 760px 下无页面级横向溢出，宽表格保留卡片内滚动，控制台未发现错误事件。
