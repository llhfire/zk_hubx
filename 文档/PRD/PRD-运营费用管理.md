## 一、模块概述

### 1.1 定位

**运营费用**是财务管理下的公司运营支出账，不是人资子模块，不是出纳账，也不是项目成本表。

它做三件事：

1. 按科目记录公司当月权责口径的运营支出（确认会发生即入账）。
2. 产出 **公共运营池**，供成本核算做运营分摊。
3. 展示每小时公摊费率，并对未来 3 个月做费用预测；工资只在看板按当前金额平移，不进台账、不进池。

替换现有 `/hr/expenses` 人资费用管理，以及财务统计里的运营费用手工账。菜单从「人资管理 / 费用管理」改挂「财务管理 / 运营费用」，旧路由重定向。

### 1.2 核心业务规则

| 规则 | 说明 |
|---|---|
| 两本账分开 | 公司花了多少钱在本模块；项目赚没赚钱在成本核算。本模块不自算项目综合成本、综合毛利率；公摊参数可只读引用（ADR-0093） |
| 一条费用一个写入方 | 办公/福利/人资行政/其他/公司级第三方由本台账写；差旅、投流、商务只读归集源模块 |
| 确认即入账 | 财务审批通过、本台账确认入账、投放日报提交 = 确认会发生。打款在财务管理模块，不决定是否进台账 |
| 工资不进台账 | 看板从工资表引用合计并做平移预测。项目人力成本仍是职级时薪 × 日报工时 |
| 大盘双口径 | 头条默认含人力 = 当月台账合计 + 工资表引用；可切不含人力。工资不是台账行，不进池（ADR-0092） |
| 部门不是落点 | 费用归属只有公共运营池 / 项目 / 线索。部门只是归口标签 |
| 只按全公司分摊 | `R_hour = 公共运营池 ÷ 全公司当月在职编制工时`。不按生产/职能切分母 |
| 不覆盖已入账 | 一键生成只补漏。已入账可改可作废，不物理删除。投影禁止在台账改 |

### 1.3 明确不做

- 出纳打款、未支付、分期、关账、反冲凭证
- 在本模块维护第二套科目树
- 税费、贷款利息、坏账科目（本阶段）
- 把工资、投流、已挂项目的直接支出打进公共运营池
- 项目交付排期当费用预算
- 项目经理进入本模块
- 按部门或「仅本人」切本模块数据
- 本模块自算项目毛利、在公摊 Tab 编成本项

## 二、费用科目

全公司一份两级字典，由系统「费用分类管理」持有。本模块不另建字典。

### 2.1 可录入的一级科目

| 一级 | Code | 默认归属 | 说明 |
|---|---|---|---|
| 办公成本 | `OFFICE` | 公共运营池 | 房租、物业、水电、网络、办公用品、保洁、公司级设备折旧 |
| 福利成本 | `BENEFIT` | 公共运营池 | 团建、节日、体检、零食、礼金 |
| 人资行政 | `HR_ADMIN` | 公共运营池 | 招聘费、培训费（非项目驻场）。**不是工资** |
| 其他支出 | `OTHER` | 公共运营池 | 无法归项的行政杂费 |
| 差旅成本 | `TRAVEL` | 项目（必填项目） | 源模块：差旅。交通/住宿/餐补等 |
| 推广成本 | `PROMOTION` | 线索域 + 必填渠道 | 源模块：线索成本投放日报。**不挂单条线索** |
| 商务成本 | `BUSINESS` | 必须选项目或线索，禁止进池 | 源模块：通用报销 |
| 第三方服务 | `THIRD_PARTY` | 必须选池或项目 | 飞书/GitHub 等公司级 → 池；项目 ECS/外包 → 项目 |

### 2.2 不是本台账录入科目

| 名称 | Code | 去向 |
|---|---|---|
| 人力成本 | `LABOR` | 项目成本桶：工时 × 职级时薪。系统内置，保留给成本核算 |
| 财务成本 / 税费 | — | 本阶段不建 |

废止旧人资页扁平 10 类（房租/水电/工资/福利…）：房租水电→办公，培训→人资行政，工资不再录入。不用 `MARKETING`、`IT_SERVICE` 作科目码。

## 三、费用归属与公共运营池

### 3.1 归属（三者互斥）

- **公共运营池**：未直接挂项目或线索、且参与分摊。
- **项目**：计入该项目直接成本，不进池。
- **线索 / 渠道**：投流挂渠道；商务可挂单条线索。不进池。

部门只是归口（谁花的）。未挂项目也未挂线索的部门支出进池。

### 3.2 进池 / 不进池

**进池**：办公场地与行政、公司级 SaaS/共用云、公司级福利、招聘培训（非项目驻场）、无法归项的杂费。

**不进池**：工资社保公积金奖金；已挂项目的差旅/云/外包/项目商务；已挂渠道或线索的投流与线索商务；税费利息坏账。

## 四、写入方与入账确认

### 4.1 谁先写

| 科目 | 写入方 | 进台账时点 | 归属 |
|---|---|---|---|
| 办公 / 福利 / 人资行政 / 其他 / 公司级第三方 | 本台账（手工、周期模板、Excel） | 确认入账 | 默认进池（第三方须选池或项目） |
| 差旅 | 差旅模块 | 财务审批通过 | 项目 |
| 推广 | 线索成本·投放日报 | 提交净消耗（消耗−退款），按月按渠道汇总 | 渠道 |
| 商务 | 通用报销 | 财务审批通过 | 项目或线索 |
| 项目级第三方 / 外包 | 本阶段允许本台账手工挂项目；后续接供应商付款 | 确认入账 / 付款确认 | 项目 |
| 工资 | **不进台账** | — | — |

通用报销不再录差旅。Excel 只是本台账写入方的批量入口。

### 4.2 发生日与归属月

- **发生日**：业务日期（租期、出差日、账单月），不是点确认的那天。
- **归属月**：进哪个月的台账、池和看板。默认 = 发生日所在月，确认时可改。
- 7 月物业 8 月才确认、归属仍选 7 月 → 改的是 7 月池。

### 4.3 已入账之后

- 本台账自己写的：可改金额、说明、科目、归属、归属月；可 **作废**（不物理删除）。作废后退出池和实际数。改和作废记痕迹。
- 改当月记录 ≠ 模板调价。
- 源模块投影：台账禁止改金额、科目、归属。源单改，投影跟着变；源单不再「确认会发生」则投影作废。
- 不关账。改完池和 `R_hour` 当场重算。

## 五、周期费用模板

| 类型 | 生成结果 | 例子 |
|---|---|---|
| 固定金额 | 生成即入账 | 房租、专线、公司级 SaaS |
| 浮动金额 | 待确认草稿（带上月金额），确认后才进池、才进实际数 | 水电 |

- 调价必须指定生效起始月；生效月之前已入账金额不变。
- 同一模板 + 同一归属月已有入账记录 → 再生成跳过。一键生成只补本月尚未出账的模板。
- 不做每月 1 号静默自动入账。
- 停用：已入账月份不动；停用月及之后不再生成。

## 六、公摊费率

工天与报价工作日不是一套日历。

```
单人当月编制工时 = 在职期间 ∩ 当月工天日历的工天数 × 8
全公司当月在职编制工时 = Σ 单人当月编制工时
R_hour = 公共运营池 ÷ 全公司当月在职编制工时
```

- **工天**：大小周（大周周一至周六，小周周一至周五，周日一律休）+ 扣法定节假日 + 加回调休上班。每日 8 小时。
- 工天日历由基础工具持有，本模块只读当月工天数。日历未就绪时，α 可手工维护每月工天数，公式不变。
- 入职日、离职日当天若是工天则计入。
- 只按全公司除，不按生产/职能切分母。
- 未摊完的池留在公司。看板显示已分摊 / 未分摊。
- 职级时薪分母本次不改（工资表仍可用其现有名义工时）。
- 废掉公摊代码里写死的人数 5 和 176 小时。
- 本模块展示 `R_hour`；乘到项目上由成本核算的运营分摊做。

## 七、预测

窗口：过去 3 个月已入账 + 当月 + 未来 3 个月。预测 **不写入台账**，不进当月池。

| 来源 | 未来月 | 可信度 |
|---|---|---|
| 固定金额模板（未停用、在生效期内） | 按模板金额 | 确定 |
| 已确认且归属月在未来的记录 | 按入账金额 | 确定 |
| 浮动模板未确认、差旅/商务/推广/无模板杂项 | 该科目近 3 个已入账月 WMA（0.5 / 0.3 / 0.2；缺月则有几月用几月；无历史为 0） | 预测 |
| 工资 | 工资表最近已出账月合计 **原样复制** | 平移（含人力口径可进头条和单独堆叠层；不含人力则不加） |
| 项目交付排期预算 | 不做 | — |

工资表能拆经常性薪酬则只平移经常性；拆不开则整表平移，图例标明可能含奖金。未来月可另算「预测费率」并标明预测。

## 八、页面结构

五个 Tab，挂在财务管理。主操作按 Tab 分放，不设全局工具栏。科目 Tab 读写系统费用分类同一棵树（ADR-0094）。

| Tab | 主操作 |
|---|---|
| 费用大盘 | 含人力 / 不含人力切换；导出（当月已入账、未作废） |
| 费用台账 | 录入抽屉、Excel 导入、导出（当前筛选）、从模板补生成 |
| 周期模板 | 新建模板、一键生成当月 |
| 公摊参数、科目 | 不放录入、不放导出 |

### Tab 1 费用大盘

- KPI：默认含人力头条（当月台账合计 + 工资表引用），可切不含人力（只看当月台账合计）；支撑卡为公共运营池、项目/线索直接、每小时公摊费率、工资引用（平移口径）。
- 6 个月流式面积堆叠：按一级科目八层。含人力时工资垫最底下一层（不是台账科目）；不含人力时工资不进堆叠。差旅与商务分列；图例用推广，不叫市场推广。
- Now 轴：左侧已入账实色；当月未完用确定模板补齐；右侧未来 3 个月确定数实色 + 预测半透。
- 异动只这三条：科目环比激增默认 > 30%、固定模板本月未生成、浮动待确认逾期。不挂差旅超标或报销待办。
- 排行：部门归口、项目直接支出两块分开，都只用本台账已入账直接支出。部门不加公摊/工资/人均；项目不加公摊/人工/合同/成本率。不展示项目毛利率。不混成一张综合成本表。

### Tab 2 费用台账

- 筛：归属月、一级科目、费用归属、来源（手工 / 周期模板 / Excel / 差旅 / 推广 / 报销）、作废与否、搜索。来源不含薪酬封账、本阶段不含合同付款。
- 本台账写入科目可新增 / Excel 导入 / 从模板补生成。
- 来源 Tag 跳转源单（只读）。投影行不可改金额科目归属。
- 凭证预览（本台账自己写的附件）。
- 导出当前筛选明细（xlsx）：单号、发生日、归属月、科目、归属、金额、来源、经办、状态。不含工资行，不含公摊结果表 / 合同 / 毛利率。

### Tab 3 周期模板

- 固定 / 浮动、调价（财务）、生成与确认（财务和人资行政）。
- 调价记录表。

### Tab 4 公摊参数

- 当月池金额、工天数、在职编制工时、`R_hour`、已分摊 / 未分摊。
- 公式条：`R_hour = 公共运营池 ÷ 全公司当月在职编制工时`（入离职按工天折算，不用整月人头）。
- **公摊结果表**（只读引用成本核算 / 精益交付）：项目工时、人力成本、台账直接支出、工时×R_hour、合同标的、综合毛利率。本模块不写入、不另算。点项目进精益交付或项目成本页。
- 只读工天日历摘要。
- 底部：预警阈值（默认 30%，不放进科目行）、模板生成提醒。

### Tab 5 科目

- 系统费用分类的本模块入口，读写同一棵两级树。
- 可录入八个一级；`LABOR` 只读，标明不是本台账录入科目。
- 新增/改二级写回系统树；不开放任意新增一级。
- 无科目级脱敏字段；差旅默认归属仍是项目或线索。

## 九、权限

本模块只给总经办 / 财务主管与人资行政。项目经理和普通员工不进本模块。不使用 `department` / `self` 数据权限。

| 能力 | 总经办 / 财务主管 | 人资行政 |
|---|---|---|
| 大盘（运营支出、池、费率、未分摊） | 明文 | 明文 |
| 工资平移合计 | 明文 | 明文 |
| 本台账写入记录 | 增改作废 | 增改（办公/福利/人资行政/其他/公司级第三方） |
| 差旅/投流/商务投影 | 只读跳源单 | 只读 |
| 模板调价、停用 | 是 | 否 |
| 一键生成 / 确认入账 | 是 | 是 |
| 公摊参数 | 明文 | 明文 |
| 科目树 | 系统管理权限 | 只读 |

项目上的差旅 / 云 / 外包在项目详情和成本核算看。普通员工只在差旅 / 报销里看自己的单。无权限者不显示工资平移块，不在台账行打 `***`。

## 十一、分阶段实施

1. **α 原型**：替换 `/hr/expenses` 为四 Tab + 录入抽屉；科目树收到八个可录入一级；周期模板（固定/浮动/调价/不覆盖）；大盘 6 个月 + 工资平移 mock；公摊参数用手工工天数。
2. **打通只读归集**：差旅已审、投放日报净消耗、通用报销已审 → 台账投影；作废与痕迹。
3. **工天日历就绪后**：公摊分母改读大小周日历 + 在职编制工时；废掉 176 与人数 5。
4. **成本核算接池**：运营分摊读取本模块池和费率（另页，不在本 PRD 做项目毛利表）。
5. **β**：D1 持久化、权限落地。供应商付款归集可后置。
6. **α UX 重构**（2026-08-21 grill，见 `operating-expense-restyle.md`）：五 Tab 视觉与入口；大盘双口径；公摊只读结果表；科目入口。不改入账与 `R_hour` 公式。
