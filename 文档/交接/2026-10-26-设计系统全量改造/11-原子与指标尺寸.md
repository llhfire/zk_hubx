# 11 · 原子标签与 MetricCard 尺寸（2026-10-28）

## 结论

这一组里，标签被拉宽是实样容器的问题；指标卡被拉宽是实样网格没有业务列宽。组件本身继续保持：标签随文案，指标卡填满单元格。

## 尺寸契约

| 组件 | 默认 | 变体 | 最小宽度 | 推荐容器 | 窄屏 | 空值 / 长文案 |
|---|---|---|---|---|---|---|
| `StatusTag` | `small`，高 20px，左右 6px | `default` 高 22px，左右 8px，只用于页头强调 | 随文案 | 列表状态列约 120px。标签不撑满列 | 仍单行 | 未知状态走 `resolveStatus` 的「未定义」。长文案不换行，列不够时允许溢出，不省略状态文案 |
| `GradeTag` | 22×22，只一个字母 | 无 | 22px | 客户/项目等级列 88px | 仍是方标 | 未定是 `?`，不映射成 C |
| `CountdownTag` | 高 20px | 无。临期阈值默认 3 天 | 随文案，空值约 24px | 与 `DateText` 并排，日期列约 168px | 仍单行 | 空值是 `—`，不是 0 天。`余 N 天` / `今天截止` / `逾期 N 天` |
| `MetricCard` | 填满父级单元格，无自身最大宽度、无卡片底 | 无 small/large。色只用 `tone` | 由网格保证 ≥160px | 4 列业务行，整行不超过 880px | 实样在 768px 改为 2 列 | 空值由调用方传入，组件不把缺数变成 0 |

芯片（前三个）使用 `width: fit-content`、`flex: 0 0 auto`、`align-self: flex-start`，避免纵向 flex 把背景拉到说明文字的宽度。`MetricCard` 保持 `width: 100%`。

## 实测

`/ui-library` 模块组件页签，1440 视口：

- 120px 列里的 small「需求调研」62×20；同文案 default 66×22。
- 88px 等级列里的 `S` 为 22×22。客户列表 `/customers` 的等级列也是 88px 列、22px 方标。
- 「余 3 天」从被说明文字拉到 82px，收回 49px；「逾期 5 天」从 88px 收回 61px；空值为 24×20。
- 指标实样整行锁在 880px，四张卡片各约 211px。内容区窄于 880px 时整行随内容区收缩（实测约 869px，卡片约 208px）。
