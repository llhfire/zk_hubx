## 二、硬编码色怎么清零的

### 1. 先补 token，再替换

直接改成 `var(--某个已有色阶)` 会让语义漂移。本次新增了 24 个 `--ds-doc-*`（文档复刻）
和 16 个 `--ds-viewer-*`（阅读器深色外壳），把「纸、墨、线、外壳、遮罩」这些
**不属于产品色阶但真实存在**的颜色显式命名。

### 2. 内嵌写法要整串扫

真正的坑不是 `color: '#fff'`，而是：

```tsx
border: '1px solid #e5e6eb'                       // 色值嵌在简写里
boxShadow: '0 4px 12px rgba(0,0,0,.12)'           // 嵌在阴影里
background: 'linear-gradient(…rgba(…)…)'          // 嵌在渐变里
borderBottom: '1px solid #f2f3f5'                 // ← 分写属性，门禁原本扫不到！
```

门禁改为对**整串属性值**做 `/#hex|rgba?\(数字/` 扫描，只有 `var(...)` / `rgb(var(...))` 放行。

**第 4 种是本次尾声才发现的漏检**：原正则的键名是 `color|background|border|...`，
`borderBottom` / `borderTop` / `borderLeft` / `borderRight` / `borderColor` / `outline` /
`fill` / `stroke` 全都不在列表里。补上门禁后立刻抓出：

- `finance/travel/trip/TripDetail.tsx` 2 处 `borderBottom/borderTop` 硬编码 → 改 token
- `sales/quotation/components/QuotePageThumbnails.tsx` 7 处（复刻文件，也一并改 token）

修完这一条，`facsimile` 例外**已经不需要了**——该文件现在 0 处硬编码色，
只剩 42 处裸数字字号/圆角（那才是它真正需要的豁免）。预算表里保留是因为
裸数字确实还在，理由在 [05](05-门禁与预算.md)。

### 3. 需要浅色底纹时用 `color-mix`

```tsx
background: 'color-mix(in srgb, rgb(var(--primary-6)) 6%, transparent)'
```

不写死半透明色，也不新造 token。

## 三、字号与圆角怎么收敛的

字号一律映射到产品阶梯，映射表：

| 原值 | token | 语义 |
|---|---|---|
| 10px | `--ds-text-micro` | 图表刻度、表格脚注 |
| 11px | `--ds-text-caption` | 表格次要列、卡片副标题 |
| 12px | `--text-xs` | 辅助文字 |
| 13px | `--ds-text-dense` | 列表主行、稠密正文 |
| 14px | `--text-sm` | 正文 |
| 16px+ | `--text-base` / `--text-xl` / `--text-2xl` | 标题 |

本次把 1017 处裸数字字号降到 32 处，剩余集中在
`sales/quotation/components/QuotePageThumbnails.tsx`（5.5 / 6 / 6.5 / 7 / 8 / 13px，
A4 缩印排版，不在产品阶梯上）。

圆角同理：201 → 10，剩余 `borderRadius: 2`（缩印表格单元格）与 `4`（缩略图外框），
同一文件，同一理由。

## 四、为什么内联视觉样式总数先涨了 631（后又降回 2067）

`visualInlineStyle` 统计的是**出现次数**，不管值是不是 token。
本次涨的原因只有一条：**把裸数字换成了 `fontSize: 'var(--text-xs)'`，
原本不匹配（值不是引号开头）的写法现在匹配了。**

按文件核过，涨的全部是「裸数字 → token」这一种，没有一处是新增视觉样式：

| 文件 | HEAD → NOW | 新增的键 |
|---|---|---|
| `Stage3WebAutomation.tsx` | 47 → 133 | 全是 `fontSize`（76 处，原来是裸数字 14/13/12/11/10） |
| `AllLeads.tsx` | 31 → 56 | 全是 `fontSize`（22 处） |
| `Stage4Approval.tsx` | 22 → 62 | 同上 |
| `FileFlowWorkbench.tsx` | 37 → 73 | 同上 |

从键名分布看得最清楚（`Stage3WebAutomation.tsx`）：

```
HEAD keys: background:16, color:22, border:5, borderRadius:3, boxShadow:1
NOW  keys: background:16, color:22, border:5, borderRadius:3, boxShadow:1, fontSize:76
```

**原有 6 个键一个没少也没多**，只多了 `fontSize`。所以这个指标**本来就不是归零目标**，
见 [05](05-门禁与预算.md)。

10-27 的语义迁移之后它回落到 **2067**（-221）。回落路径和上涨路径不同：不是把 token
改回裸数字，而是**把整段内联样式连同结构一起搬进设计系统组件**——页面侧那几十行
`style={{ fontSize: 'var(...)' }}` 消失了，同样的表达变成 `<MoneyText>` / `<DateText>` /
`<FileList>` 的一个 prop。所以正确的收口方向是「换组件」，不是「换写法」。

## 五、字体统一

- 所有金额、数量、日期走 `MoneyText` / `DateText` / `MetricCard`，字体栈统一
  `"Inter Variable", Arial, sans-serif`（M-022）。
- `design-system/` 之外**禁止声明 `fontFamily`**，门禁 `fontFamilyOutsideDs` 硬性 0。
  本次把引号表里 20 处内联 Inter 字体改成容器上的 `.hubx-numeral` 类。
