## 一、模块概述

### 1.1 定位

报价流程管理是销售域的核心模块，覆盖从功能清单到合同签约的完整报价链路。系统提供两种操作模式：**数据流转**（工作台在线操作）和**文件流转**（上传文件），审批统一走系统。

### 1.2 核心业务规则

| 规则 | 说明 |
|------|------|
| 签约前报价 | 可多份并存（独立编号）；同时只有一份已确认，该份为有效报价，可生成主合同 |
| 签约后补充报价 | 主合同批准后方可新建；可多份；总价为变更额，可为负；评估人天可为 0 |
| 补充报价流程 | 与主报价流程一致；客户件同一套标准报价单，只含本单变更 |
| 功能清单耦合 | 功能清单依附于报价单，不单独设置 |
| 审批方式 | 主报价走「报价审批」、补充报价走「补充报价审批」；提交时拍快照，默认三人并行会签 |
| 盖章方式 | 会签通过后进入待盖章；盖章人来自审批流程配置；电子PDF自动生成 + 线下扫描件可选上传 |
| 校验规则 | 仅提醒，不卡流程 |

## 二、状态机

### 2.1 报价单状态

```
[草稿]
  ↓ 提交评估
[待评估]
  ↓ 技术评估人完成评估
[待报价]
  ├─ 退回改清单 → [草稿]（评估作废）
  ├─ 退回技术重评 → [待评估]
  ↓ 销售提交审批
[待审核]
  ├─ 驳回 → [已驳回] → 销售修改 → [待审核]
  │               ├─ 退回改清单 → [草稿]
  │               └─ 退回技术重评 → [待评估]
  ├─ 会签通过 → [待盖章]
  │               ↓ 盖章
  │            [已盖章]
  │               ├─ 退回盖章 → [待盖章]
  │               ↓ 发送客户
  │            [已发出]
  │               ├─ 客户确认 → [已确认]
  │               ├─ 撤回发出 → [已盖章]
  │               └─ 客户不满意 / 内部停跟 → [已废止]
  （已发出超过有效截止日：打过期标记并通知销售，状态仍为已发出，可已确认、撤回发出或已废止）
  └─ 撤回 → [待报价]
```

### 2.2 状态定义

| 状态 | 说明 | 可操作角色 |
|------|------|-----------|
| 草稿 | 新建后可编辑；创建人可删除。撤回审批回到待报价，不回草稿 | 创建人 |
| 待评估 | 已提交，等待本单技术评估人评估 | 技术评估人 |
| 待报价 | 评估完成，等待本单销售报价 | 销售 |
| 待审核 | 已提交审批，等待三人会签 | 黄奕/罗总/闵总 |
| 已驳回 | 审批人驳回，需修改 | 销售 |
| 待盖章 | 会签全部通过，等待配置中的盖章人盖章 | 盖章人（审批流程配置） |
| 已盖章 | 盖章完成，可下载PDF | 销售/产品经理 |
| 已发出 | 已发送客户 | 销售 |
| 已确认 | 客户确认；取得生成主合同资格（向导预填，人工确认后才创建） | 销售 |
| 已废止 | 报价唯一死态。已生成对应合同的已确认报价须先作废该合同才能废止 | — |

## 四、报价工作台

### 4.1 工作台结构

一个工作台，四个步骤，不同角色打开自动定位到当前步骤。

```
┌─────────────────────────────────────────────────────────┐
│  报价工作台 · {客户名} · {项目名}                        │
├─────────────────────────────────────────────────────────┤
│  步骤：❶ 上传功能清单  ❷ 人天评估  ❸ 增项报价  ❹ 审批盖章│
├─────────────────────────────────────────────────────────┤
│  {当前步骤内容}                                          │
│                                                         │
│  [上一步]                          [下一步/提交]        │
└─────────────────────────────────────────────────────────┘
```

### 4.2 步骤1：上传功能清单

**操作人：** 产品经理 / 任何有报价权限的人

**页面元素：**
- 上传区域（支持 .xlsx .xls 拖拽上传）
- 功能清单表格（解析后展示，支持在线编辑）
- 模块层级：两级（模块 + 子功能），另挂端/平台；更深写在描述里
- 来源标签：手动创建 / 文件上传

**操作：**
- 上传Excel → 自动解析为结构化数据
- 在线创建 → 手动填写模块/子功能/描述
- 解析后可编辑修改
- 点击「保存」→ 保存为草稿
- 点击「提交评估」→ 至少一行有效功能才能到步骤2

### 4.3 步骤2：人天评估

**操作人：** 罗总 / 被指派技术

**页面元素：**
- 功能清单（只读展示）
- 评估表单（可自定义岗位，按模块填写人天）
- 技术备注
- 支持Excel导入

**操作：**
- 查看功能清单（只读）
- 填写各模块各岗位人天（必须全部填完才能提交）
- 填写技术备注
- 可导入Excel评估表
- 评估提交后罗总不可自行撤回再改；销售可在待报价/已驳回退回技术重评
- 点击「完成评估」→ 主报价总人天须 > 0；补充报价允许 0

### 4.4 步骤3：增项报价

**操作人：** 销售

**页面元素：**
- 人天成本摘要（只读）
- 增项区域（预设模板 + 自由增项）
- 工期配置（可手动修改）
- 利润率（统计项：改岗位成本或总价后反算；不按目标利润率倒推售价）
- 报价汇总
- 系统校验提醒（仅提醒，不卡流程）

**操作：**
- 查看人天成本（只读）
- 添加增项（可选关联功能模块）
- 配置工期、利润率
- 查看汇总（系统自动计算）
- 支持保存报价模板
- 点击「保存」→ 保存为草稿
- 点击「提交审批」→ 流转到步骤4

### 4.5 步骤4：审批盖章

**操作人：** 黄奕/罗总/闵总（审批）+ 黄海（盖章）

**页面元素：**
- 报价详情（只读）
- 审批记录
- 审批意见输入
- 通过/驳回按钮
- 盖章区（三人通过后显示）

**操作：**
- 审批人查看报价详情
- 填写审批意见
- 点击「通过」或「驳回」
- 三人全部通过后，黄海执行盖章
- 系统自动生成电子PDF
- 可选上传线下盖章扫描件

## 五、两种数据流转模式

### 5.1 数据流转（默认）

```
用户在工作台上在线操作
→ 数据存入结构化表
→ 系统自动计算、校验、通知
```

### 5.2 文件流转

```
销售上传功能清单文件 → 系统解析为两级清单（序号/模块/子功能/描述/备注）
→ 技术上传评估文件，必填评估工期、总人天（备注可选）；评估文件不解析成人天明细
→ 销售必填报价工期、总金额、付款方式、有效期、增项表（可 0 行；利润率与质保年数可选）
→ 不自动生成 PDF；销售在在线文档编辑器中出最终电子版，并保存打印扫描件
→ 合同预填只读重要信息表
```

**文件流转入口：** 用户在创建报价单时可选择「文件上传」模式。  
「生成报价单」指按标准件生成客户 PDF。

## 六、与其他模块的数据关联

### 6.1 关联关系

```
线索 ──1:N──→ 报价单（一个线索可有多份报价）
报价单 ──1:1──→ 合同（有效报价转合同）
合同 ──1:N──→ 补充报价（签约后可有多份）
补充报价 ──1:1──→ 补充合同
```

### 6.2 数据带入规则

| 场景 | 带入规则 |
|------|----------|
| 报价单 → 合同 | 向导预填全部可映射数据，销售确认后创建（不自动插入合同） |
| 补充报价 → 补充合同 | 向导预填可映射数据（含结构化付款期次），人工确认后创建 |

### 6.3 线索详情页集成

- 线索详情页右侧操作区 → 报价Tab
- 报价Tab展示该线索下所有报价单列表
- 点击「新建报价」→ 打开工作台（线索当前已终止/垃圾时不可新建；恢复后未终态单可继续）

## 七、权限控制

### 7.1 创建权限

任何有报价权限的人均可创建报价单。

### 7.2 编辑权限（按步骤控制）

| 步骤 | 可编辑角色 | 可编辑内容 |
|------|-----------|-----------|
| 步骤1 | 创建人 | 功能清单（数据流转）或上传/改清单文件 |
| 步骤2 | 技术评估人 | 人天评估或评估文件+重要信息 |
| 步骤3 | 销售 | 增项/报价表单；文件流转在线文档 |
| 步骤4 | — | 不可编辑正文（仅会签/盖章）；文件流转扫描件可在待盖章后上传 |

### 7.3 查看权限

能打开：创建人、线索负责人、技术评估人、配置中的会签人与盖章人、有报价权限的管理员。能打开即可看岗位成本和利润率（客户件不印）。

## 八、消息通知

| 触发事件 | 通知对象 | 通知内容 |
|----------|----------|----------|
| 创建报价单并提交评估 | 技术评估人 | 有一条报价单待评估 |
| 评估截止已过仍待评估 | 技术评估人 | 评估已过期（状态不变） |
| 完成评估 | 创建人/销售 | 人天评估已完成 |
| 销售提交审批 | 该业务类型配置中的会签人 | 有一条报价单待审核 |
| 任一审批人驳回 | 销售 | 报价单被驳回 |
| 会签全部通过 | 配置中的盖章人 | 有一条报价单待盖章 |
| 盖章完成 | 销售/创建人 | 报价单已盖章 |
| 报价单超期未确认 | 销售 | 报价单已过期（状态仍为已发出） |
| 补充报价提交审批 | 「补充报价审批」配置中的会签人 | 有一条补充报价待审核 |

## 九、系统校验（仅提醒）

| 校验项 | 规则 | 提示方式 |
|--------|------|----------|
| 人天×单价 = 人力成本 | 应相等 | 黄色警告 |
| 各增项 + 人力成本 = 总报价 | 应相等 | 黄色警告 |
| 利润率 ≥ 最低利润率 | 默认 15%（系统配置，与项目成本偏低同一口径）；只黄灯不拦截 | 黄色警告 |
| 评估工期 ≤ 报价工期 | 按工作日比（只跳周六日） | 黄色警告 |
| 报价有效期 | 发送客户日起算，默认 30 天（系统配置）；超期仅标记+通知 | 提示 |

## 十一、PDF生成

### 11.1 电子PDF（系统自动生成）

**数据流转：** 按标准件自动生成。待报价/已驳回预览带草稿水印；盖章时定稿无水印正式版并锁定。不印岗位成本、日单价、利润率。

**文件流转：** 不自动生成。编辑器初稿为标准件骨架 + 重要信息与已解析清单预填；销售改完保存最终电子版，另存打印扫描件。

### 11.2 扫描件

- 打印最终电子版 → 盖章 → 扫描 → 上传
- 下载时可选择电子版或扫描件
