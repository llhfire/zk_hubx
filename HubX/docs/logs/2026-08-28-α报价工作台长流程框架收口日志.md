## 实现结果

- 二级页面增加“报价管理 / 报价中心 / 当前报价单”面包屑。

- `ProcessMetricGrid` 单行展示客户、当前阶段、总报价、评估人天、待办人与有效期。
- `ProcessWorkspace` 构建 70:30 主辅区：左侧保留四阶段业务工作台，右侧展示协作人与线索/合同/客户关联。
- 阶段导航支持只读回看已到达阶段，未到达阶段禁用；顶部流程始终保持真实当前阶段。
- 独立路由与线索/项目全屏抽屉的嵌入模式共用同一业务布局。
