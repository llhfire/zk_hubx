一、业务流程与端到端闭环

1. 全流程线上化原则：系统目标流程统一明确为“客户沟通留痕 → 需求梳理 → 功能清单 → 工作量评估 → 成本核算 → 对外报价 → 报价审批 → 合同 → 项目执行 → 回款/开票 → 资料归档”。已上线的功能必须全程在系统内完成，禁止出现“线上录一次、线下私聊再做一次”的双轨脱节。

2. AI 辅助边界与约束：AI 可用于提炼功能清单与工作量概算，但严禁无边界自行补充客户未提出的需求，避免导致报价虚高与验收争议。

二、报价配置与审批流改造

1. 报价单数据联动：功能清单直接作为报价单生成的前置基础，岗位工时细化至前端、后端、UI、产品、测试等维度。

2. 价格上浮调整：原始成本保持锁定，提供“按比例上浮”与“按固定金额上浮”两种调整模式，调整金额需合理分摊到人天。

3. 统一审批中心：报价提交后直接在系统内审批中心流转，支持审批意见填写与多轮驳回历史留痕。

三、回款、开票与成本核算控制

1. 回款计划模板化：付款比例采用下拉模板（如 3:3:3:1、4:5:1 等），选择模板自动带出期数和回款条件，并允许各期独立微调。

2. 状态机严格互锁：未回款可拆分期次，已开票可发起冲红；资金一旦实际到账则禁止拆分，规范财务合规风险。

3. 成本核算分析：人工成本支持“按人员”与“按工作性质”双维度汇总统计，日报填写强制关联工作性质。
