# ZK HubX 领域扩展建议

> 基于全网调研，对标标准企业OA/ERP，精简合并为6个域
> 更新时间：2026-08-14

---

## 当前 vs 建议

```
当前4域                          建议6域
┌──────────┐                    ┌──────────┐
│  销售域   │ ──不变──→         │  销售域   │
├──────────┤                    ├──────────┤
│  交付域   │ ──扩充──→         │  交付域   │  +工时/资源/需求/质量
├──────────┤                    ├──────────┤
│  运营域   │ ──拆分──→         │  运营域   │  保留组织/审批/工作台
├──────────┤                    ├──────────┤
│  财务域   │ ──不变──→         │  财务域   │  +预算管理
└──────────┘                    ├──────────┤
                                │  人力域   │  新增：招聘/考勤/薪酬/绩效
                                ├──────────┤
                                │  行政采购域│  新增：采购/资产/合规
                                └──────────┘
```

## 6域架构

| 模块 | 说明 |
|------|------|

| 客户管理 | 4项 |
| 报价管理 | 7项 |
| 合同签约 | 5项 |

### 二、交付域（项目·交付）← 扩充
> 现有22项 + 新增12项 = 34项

| 模块 | 说明 |
|------|------|
| 项目管理 | 9项（已有） |
| 日报工时 | 8项（已有） |
| 合同交付跟进 | 4项（已有） |
| 知识库 | 4项（已有） |
| **工时管理** | **新增** 工时填报、审批、统计、与成本关联 |
| **资源管理** | **新增** 人力池、资源分配、冲突检测、利用率分析 |
| **需求管理** | **新增** 需求池、优先级、评审、追踪、变更控制 |
| **质量管理** | **新增** Bug管理、测试用例、验收标准、质量报告 |

### 三、运营域（组织·行政）
> 现有22项，精简保留核心

| **制度与流程** | **新增** 制度发布、流程文档、SOP管理 |

### 四、财务域（资金·风控）← 扩充
> 现有18项 + 新增4项 = 22项

| 模块 | 说明 |
|------|------|
| 回款管理 | 5项（已有） |
| 开票管理 | 4项（已有） |
| 成本核算 | 5项（已有） |
| 财务审批 | 4项（已有） |
| **预算管理** | **新增** 项目预算、部门预算、预算执行、超支预警 |

### 五、人力域（招聘·考勤·绩效）← 新增
> 从运营域拆出，深度扩展

| 模块 | 说明 |
|------|------|
| 员工管理 | 列表、岗位、入职离职、调岗 |
| 考勤管理 | 打卡、加班、请假、月度汇总 |
| 薪酬管理 | 薪资结构、社保公积金、个税、工资条 |
| 绩效管理 | KPI/OKR、考核周期、多维评估 |
| 招聘管理 | HC申请、简历库、面试安排、Offer |
| 培训管理 | 培训计划、课程、学时记录 |

### 六、行政采购域（采购·资产·合规）← 新增

| 模块 | 说明 |
|------|------|
| 采购管理 | 采购申请、询价比价、供应商管理、到货验收 |
| 资产管理 | IT设备台账、领用归还、折旧、盘点 |
| 合同合规 | 合同全生命周期、资质管理、风险预警 |
