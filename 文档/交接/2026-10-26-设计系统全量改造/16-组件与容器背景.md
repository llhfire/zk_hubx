# 16 · 组件与容器背景

> 2026-10-28。尺寸审计（切片 11–15）之后，用户看组件库时提出背景分不清。本切片只记这一轮，不重开尺寸组。

## 用户原话

1. 「组件的背景色跟容器的背景色混淆了」
2. 第一次改完之后：「现在组件融入了容器里面的灰色背景。更难看了。」

## 最终决定

演示区和详情指标都用白底，靠边框分开。不要用深灰托底把组件托进同一层灰里。

| 表面 | 最终 |
|---|---|
| `.ui-library-preview` | `--color-bg-2`（白），描边 `--color-border-2` |
| 上传区、文档行、岗位费率卡等组件自身的 `--color-fill-1` | 保持不变。白演示区上它们是浅底，不再和容器同色 |
| 项目 / 客户 / 员工 / 出差详情，以及报销、借款、出差列表的指标块 | 页面覆盖改回 `--color-bg-2` |
| 项目、客户、员工指标上的 3px 彩色侧条 | 删除。`DESIGN.md` 禁止 3px 以上彩色侧边条 |
| 出差车票「当前」 | 去掉 `border-left: 4px`，改成整圈 `border-color: rgb(var(--primary-6))` |
| 指标内进度槽 | 不再强制白底，回到组件自己的 `--color-fill-2` |
| 主辅布局实样 | 仍包在 `.ui-library-preview` 里，现在是白底上的白卡片，靠边框区分 |

曾经试过把演示区改成 `--color-fill-3`（`rgb(229, 230, 235)`），并把指标块改成 `--color-fill-2`。实测上传区、文档行、岗位卡仍是 `rgb(247, 248, 250)`，整块演示区变成灰坑，用户判定更难看。这套已撤回。

## 浏览器核对

α 开发服务器 `http://localhost:5173`，视口 1440×900。

- `/ui-library` → 模块组件：演示区 `rgb(255, 255, 255)`；上传区、文档行、岗位费率卡 `rgb(247, 248, 250)`；主辅布局里的区块卡为白。
- `/projects/13`：六块指标 `rgb(255, 255, 255)`，所在卡片也是白；`::before` 的 `content` 为 `none`，侧条不在。

宿舍床位上和房态同色的状态标签没有改，那是状态色，不是容器底。

## 门禁与豁免

- 借款列表 `.loan-cell-progress__bar` 的 `transition: width` 是按已还比例填充，不是面板变宽。这条规则抽不出可单独忽略的值，所以只在 `HubX/packages/ui/src/app/pages/finance/travel/loan/loanList.css` 豁免 `layout-transition`。记录在 `.impeccable/config.json`。不要把这条豁免扩到别的文件。
