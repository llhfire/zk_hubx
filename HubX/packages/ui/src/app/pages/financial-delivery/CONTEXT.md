# 精益交付（财务交付视角）术语表

> 模块级术语表。全局术语以 `HubX/CONTEXT.md` 为准；本模块硬决策见 `HubX/docs/adr/0086`–`0088`、`0091`。

## 业务单（Case）

一笔业务在精益交付页的**财务交付视角**（主术语表第四视角）。**轻实体**（ADR-0086/0088 修正案）：持有管理参数（targetMargin / budgetCap / commercialCap）与自有 10 态状态机（草拟/报价/协商/已签/交付/挂起/验收/催款/完结/终止；协商中、催款中无可派生来源，由人推进）；业务明细事实一律不持有--报价/评估来自报价域，合同/回款来自合同域，成本来自成本流水，一切指标派生。编号 `CASE-YYYY-MM-DD-序号`，是唯一不为写入服务的业务编号（ADR-0088）。与报价 1:N（主报价 + 补充报价）。

_Avoid_: 把 Case 当作可写业务明细的数据实体、另建第二套报价/评估挂在 Case 下、用回款口径利润率做健康判定

## 成本流水（CaseCostItem）

成本域的唯一原子事实。分五类：**人工 / 差旅 / 推广 / 商务 / 第三方**（ADR-0091 修订 ADR-0086 五类）。获客成本分摊（含原运营分摊口径）归推广类；硬件采购归第三方类。`actual`=已发生，`forecast`=未发生（预测）。totalCost、EAC、成本结构、趋势全部由它派生。

_Avoid_: 手工维护汇总成本数、把差旅归商务、另设运营/硬件独立类、出差补贴归人工类

## 商务上限（commercialCap）

Case 管理参数之一，只管控**商务类**（宴请招待）支出；差旅类不受其管控（差旅走差旅模块硬软标准，ADR-0089 线）。

## EAC（完工估算）

Σactual 成本流水 + Σforecast 成本流水。只有一个值，没有第二套预测数。

## 回款口径收入（actualRevenue）

累计已到账回款（合同域 collectionRecords），收付实现制（ADR-0087）。只用于 WIP 与现金流展示；健康判定用**全周期利润率**（有效标的额 vs EAC），不用回款口径--回款节奏后置会让交付前期利润率必然失真。完工百分比法是未来演进，不是当前口径。

_Avoid_: 用回款口径利润率做健康灯、用完工百分比确认收入、把应收期次计划当已收

## WIP 占用

max(0, 已发生成本 − 累计回款)：公司为一笔业务垫付的资金。WIP 天数 = 距最近一次回款的天数。

## 盈亏平衡合同额 / 底线价

模拟器输出。前者 = 利润率为 0 的合同额；后者 = EAC / (1 − 目标利润率)，谈判降价的空间下界。模拟器输入（合同额、功能范围%、商务预算、目标利润率）全部与成本链同源，不接受无来源参数。

## 事后总结（PostMortem）

结项复盘。predictedPnl = 结项时最终报价成本侧的**不可变快照**；actualPnl = 从成本流水与回款派生。毛利以金额 + 百分比双字段表达。

## 时薪公摊率

获客/推广成本分摊到项目的比率基础（项目工天 × 时薪公摊率），与运营费用模块（ADR-0076–0085）共用同一常量，两边口径必须一致。分摊结果落在推广类成本流水（ADR-0091）。

_Avoid_: 「按人天 30%」式手工分摊比例
