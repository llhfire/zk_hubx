## 二、组件能力扩展（迁移中撞出来的）

迁移过程发现原组件表达不了页面的既有形态，于是扩 props 而不是让页面回退 Arco：

| 组件 | 新增 | 触发的场景 |
|---|---|---|
| `StatusTag` | `style` / `onClick` / `onClose`；tone 从 6 扩到 9 | 快捷筛选标签、已选条件可删除、分类色（费用类型/渠道/角色） |
| `SectionCard` | `size` / `bordered` / `hoverable` / `onClick` / `style` / `bodyStyle` | 侧栏紧凑卡、嵌进卡片的无边框卡、可点击进详情 |
| `AlertBanner` | `title` / `compact` / `style`；tone 加 `success` | 卡片内一行说明、首行加粗标题 |
| `ProgressBar` | `variant="circle"` + `diameter`、`tone` 9 色、`size` 三档、`showValue` | 单个闭环比例强调、表格内联条、分类色 |
| `MetricCard` | `icon` / `badge` | 标签行图标、右上角状态角标 |
| `DescriptionsCard` | `bare` | 嵌进已有卡片/侧栏，不叠第二层描边 |
| `GradeTag` | 导出 `GRADE_TONE` | 页面需要「等级色但不是标签」（雷达图、进度条） |

## 三、状态色映射：从 7 套自建 → 类型化映射表

HEAD 有 **10 处** `STATUS_COLOR` / `StatusColor` / `getStatusColor` / `statusColorMap` 定义，
分布在 **9 个文件**（含 `QUOTE_STATUS_COLORS` / `CONTRACT_STATUS_COLOR` / `SALES_STATUS_COLOR`）。
同一个「已驳回」，合同域、报价域、线索域各有一个色值。

现在：**0 处**。统一成两种形态：

```ts
// 形态一：只要色，不要文案
const SLA_TONE: Record<string, StatusTone> = {
  normal: 'success', warning: 'warning', overdue: 'danger', contacted: 'success',
};

// 形态二：文案 + 色（StatusMap）
export const CONTRACT_STATUS: StatusMap<ContractStatus> = {
  draft: { label: '草稿', tone: 'neutral' },
  approving: { label: '审批中', tone: 'info' },
  /* … */
};
// 页面侧：<StatusTag meta={CONTRACT_STATUS[status]} />
```

命名约定（已写进规范）：`*_TONE` / `*_META`，**值只写文案和 tone，不写颜色**。
全仓现有 **32 张映射表 / 21 个文件**。

新建/改造的代表：

| 映射表 | 文件 | 说明 |
|---|---|---|
| `CONTRACT_STATUS` | `sales/contracts/utils.ts` | 合并了 4 个页面各自的合同状态文案 |
| `PROJECT_STATUS_META` | `delivery/project/types.ts` | 6 个交付页共用 |
| `INTENTION_LEVEL_TONE` / `LEAD_SOURCE_TONE` | `sales/leads/types.ts` | 线索意向等级与来源 |
| `SLA_TONE` | 5 个线索列表页 | 同一口径，抽到 `types.ts` 后可再合并 |
| `GRADE_TONE` | `design-system/primitives/GradeTag.tsx` | S=success，**不是 danger**（有回归测试锁） |

**需要「状态色但不是标签」时**（进度条、左侧强调条、金额着色、雷达图）用
`STATUS_TONE_VARS[tone].fg`，不要写 `var(--success-500)`。现已 12 个文件在用。

## 四、内容零丢失核查

迁移中有 5 处看起来「文案消失了」，逐一核实全部是**合并进了共享映射表或改由组件内部渲染**：

| 疑似丢失 | 实际去处 |
|---|---|
| 合同详情 草稿 / 审批中 / 待寄出 / 待回寄 | 合并进 `CONTRACT_STATUS`（`sales/contracts/utils.ts`） |
| 交付计划 未确认 / 未开始 / 进行中 / 已完成 | 合并进 `PROJECT_STATUS_META`（`delivery/project/types.ts`） |
| 回款时间轴的 万 / 逾期 / 天 | `MoneyText`（万）、`CountdownTag`（逾期 X 天） |
| `LeadContractHistoryPanel` 的操作时间 / 驳回原因 | `DateText` + `ApprovalFlow` 的 `comment` 位 |
| 各页 `¥${x.toFixed(2)}` | `MoneyText` |

写这条是为了下次迁移时**不要重犯「删了文案但没人发现」**——所以每一处都要能指到去处。
