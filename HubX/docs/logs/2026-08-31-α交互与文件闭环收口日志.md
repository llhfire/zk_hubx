# α 交互与文件闭环收口日志

## 范围

本轮只收口 α 版既有页面中的假交互、断路和验收文档漂移，不扩展 β 生产底座。登录、RBAC、服务端文件存储、D1 持久化以及资源/运维域仍按既有 β 与 P2/P3 计划推进。

## 已完成

- 客户列表：真实组合筛选、新建、编辑回填和结果总数。
- 合同记录：关键词、状态、签订日期筛选；新增合同进入合同向导。
- 渠道分析：日期/平台条件生效，当前结果可导出 XLSX。
- 系统配置：三组配置写入浏览器持久化存储，支持 JSON 备份与结构校验恢复。
- 报价文件：功能清单按五列 Excel 导入预览确认并支持 XLSX 导出；报价单生成 PDF，盖章后下载正式版。
- 合同文件：扫描件支持多文件上传、预览、下载和删除；无源种子文件明确禁用下载，不再伪造文件。
- 项目文件：报价附件保留上传源地址，支持预览、下载、删除；只有元数据的历史附件取消伪下载入口。
- 差旅：出差详情中的借款、报销均可新建草稿，并通过详情抽屉查看金额、状态和审批轨迹。
- 下钻：回款抽屉可进入关联项目；旧项目决算地址重定向到业务单详情的项目决算页签。
- 文档：完成 UI 修改计划翻牌，校正已编码计划说明、功能看板描述和工作记录分类。

## 验收口径

1. 真实文件只在浏览器持有源文件或页面能够生成内容时提供下载。
2. 种子数据只有文件元数据时，下载入口必须禁用或明确提示无源，不能生成同名占位文件。
3. α 会话态新增/编辑需要即时回写页面状态；系统配置额外使用浏览器持久化存储。
4. 旧地址不得再落到纯文字占位页，必须重定向到现有规范页面。
