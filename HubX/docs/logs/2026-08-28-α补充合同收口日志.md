# 2026-08-28 α 补充合同收口日志

## 收口目标

需求与金额变更只允许走：

`已批准主合同 → 补充报价 → 审批/盖章/客户确认 → 合同向导 → 补充合同 → 归档生效`

不再维护可直接填写变更金额的第二类合同对象。

## 本次完成

- 补充合同创建强制携带 `parentContractId` 与 `sourceQuoteId`，变更额不得为 0，正向增额和负向减额均保留。
- 有效标的额统一为“主合同金额 + 已归档且未作废补充合同变更额”。
- 项目 360 改为汇总有效标的额及主合同、有效补充合同的独立实收台账。
- 回款与发票页按主合同聚合有效补充合同的金额、回款期次、实收与开票申请。
- 合同变更记录、项目回款卡片和功能看板退出旧术语；功能看板补齐说明、使用流程和 ADR 地址。
