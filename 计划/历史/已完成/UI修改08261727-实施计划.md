# UI 修改 08261727 实施计划

> 来源：`research/UI修改08261727.md`  
> 执行基准：`HubX/DESIGN.md`、`/ui-library`、我的线索列表与线索详情。

## 执行原则

1. 先复用 Arco 基础控件和 HubX 模块组件，再增加业务样板。
2. 列表页统一使用明确筛选提示、固定操作列、图标操作与 Tooltip。
3. 二级以上页面使用面包屑；长流程详情复用流程概览、指标网格和主辅工作区。
4. 新增图标使用 `@phosphor-icons/react`，统一 `weight="regular"`、`size={18}`。
5. 每一阶段完成测试、构建和浏览器抽检后再进入下一阶段。
