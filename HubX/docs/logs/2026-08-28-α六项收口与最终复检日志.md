# 2026-08-28 α 六项收口与最终复检日志

## 范围

本轮仅修改 `packages/ui` 与 `apps/prototype` 的 α 页面和本地状态接缝，不改 β Workers、D1 或部署配置。

## 完成项

1. **系统配置一致性**：组织架构、用户权限、公司主体、通用配置和费用分类统一 `PageShell`、二级面包屑、20px 页头、指标板、16px 内容卡片及窄屏布局。
2. **集成与消息一致性**：企业微信、通知设置和消息中心统一页面框架；补筛选结果、状态摘要、响应式表单及图标按钮无障碍名称。
3. **局部样式债**：移除员工技能卡、线索回款/开票详情和开票提示块的装饰性彩色左边条，状态改由标签、图标和浅色底表达。
4. **合同通知去重**：签约联动桥正常成功事件改为静默，只在无法继续联动时显示一次警告；新增回归测试防止与合同操作 Toast 重复堆叠。
5. **交付闭环**：交付计划可进入项目任务和按项目筛选的日报；增加“交付物归档 → 提交验收 → 确认验收”状态门槛，状态保存在 α 本地存储。
6. **财务与售后闭环**：回款与发票页增加“期次 → 逾期 → 开票/红冲 → 售后移交”流程；仅在无逾期、全额回款、全额开票且无开票中记录时允许移交，并在售后页生成六个月维护期。
