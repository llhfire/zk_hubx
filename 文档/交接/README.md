# 文档/交接/

会话交接的**切片仓库**。根目录 `下班交接.md` 只保留「当前这一场」的索引，
正文按主题拆到这里，避免单文件膨胀到读不动。

## 结构

```
文档/交接/
  README.md                          ← 本文件：约定与索引
  <日期>-<主题>.md                    ← 已收口的单文件交接（旧格式，历史）
  <日期>-<主题>/                      ← 单次会话的切片集
    00-索引.md
    01-….md
```

## 约定

1. **根目录 `下班交接.md` 是入口，不是正文**。它只写：更新时间、一句话结论、
   当前状态表、本次切片目录、「下次开工第一件事」。
2. **正文按主题切片**，一个切片只回答一个问题（范围 / 结构 / 迁移 / 门禁 / 验证 /
   文件清单 / 踩坑 / 待办）。切片超过 ~200 行就再拆。
3. **顺手翻旧的**：上一场的切片集不删、不改，新一场读完根索引直接跳旧切片。
4. 归档文件**不是现行规范**。路径、行号、组件能力都可能已经变了，查现状看代码。
