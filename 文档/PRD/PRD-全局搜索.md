## 1. 需求背景

各业务实体分散在线索五池、客户列表、报价中心、合同列表、项目列表、员工列表各自页面的局部搜索框里。跨域找人/找单要先想「它在哪个菜单下」再进对应列表搜索，路径太长。

原型 `ZKHubX-顶部搜索栏强化.html` 画了一个「AI 生产力入口 / Copilot」的四层愿景（全局搜索 → 斜杠快捷表单 → NL2Action → AI 风险诊断）。本 PRD grill 收束后**只做第一层：全局搜索与直达**，其余层明确不做（见 §10）。

## 2. 产品目标

1. 任意页面顶栏中间提供全局搜索触发器，点击或 ⌘K 唤起弹层。
2. 一个关键词跨域检索六类实体，命中即跳各自详情页。
3. 搜索零写入、零权限差异、零 AI 承诺：诚实的能力边界。

## 3. 检索范围（六实体）

| 实体 | 检索字段 | 跳转目标 |
|---|---|---|
| 线索 | 线索名 / 公司 / 联系人 / 手机号 / 编号 | `/leads/:id`（LeadDetail360） |
| 客户 | 客户名 / 编号 | `/customers/:id` |
| 报价 | 报价名 / 编号 / 客户名 | `/quotation/:quoteId` |
| 合同 | 合同名 / 编号 / 客户名 | `/contracts/:id` |
| 项目 | 项目名 / 编号 / PM | `/projects/:id` |
| 员工 | 姓名 / 部门 / 岗位 | `/employees/:id` |

不进全局搜索：会议纪要、差旅单、费用单、日报、审批单、财务 Case（各有专属列表中心，低频伪需求）。

**死数据口径**：线索排除垃圾箱池（含已作废）；合同作废、项目搁置等其余实体照常可搜（有效历史档案）。

## 4. 匹配规则

1. 大小写不敏感；**包含匹配**，不做前缀加权。
2. 多关键词：空格分词后**每段都须命中**（AND 语义，每段命中该实体任意检索字段即可）。
3. 每类实体结果上限 **Top 5**，类内按编号/创建时间新 → 旧排序。
4. 不做拼音首字母、不做分词器。
5. 匹配逻辑为纯函数 `matchEntities(items, keyword)`，进单测（多词 AND、大小写、Top 5 截断、死线索排除四个用例）。

## 5. 数据来源（只读投影，不建副本）

- 搜索模块定义统一入口，内部读六个域的既有内存列表（α 缺省 mock、β 由 `services/` 加载后注入各域 Context 的同一份数据）。
- 线索/项目/合同/报价：读各域 Context 已加载列表（服务接缝的消费者，α/β 差异由 Context 吸收）。
- 客户/员工：读各自模块级 mockData（客户数组自 Customers 页面内联原样提取）。
- **禁止**搜索模块自建汇总数据副本或第二个 service 实例（平行第二套账）。
- β 本期**不做**服务端搜索接口：D1 数据量为集团内部量级，列表读取 + 前端内存过滤够用。
- `opts.actor` 为预留参数：权限矩阵（P0②）落地后在此接角色过滤。

## 6. 权限

本期**不按角色过滤**搜索结果。理由：详情页本身无路由级拦截，搜索层过滤是假安全；权限矩阵未落地，先拍规则必然重写；集团内部效率工具，搜索不是安全边界。权限矩阵落地后经 `opts.actor` 接缝补上，改动收敛在适配器。

## 7. 交互与视觉

### 触发器（顶栏中间）
- 灰底搜索框：放大镜图标 + 静态 placeholder「搜索线索、客户、报价、合同、项目、员工…」+ 右侧 ⌘K 徽标。
- **去掉**原型全部 AI 品牌元素：spark 渐变图标与脉冲动画、Copilot 字样、旋转 placeholder 轮播、弹层底部 Copilot 署名、快捷动作 chips 条。品牌跟着能力走，L3 落地那天再加回。
- MainLayout Header 由右对齐改为三段式（左空 / 中触发器 / 右图标组）。
- 窄屏（<md）隐藏触发器。

### 弹层
- 自绘轻量弹层（fixed 遮罩 + 面板），不用 Arco Modal。
- 打开自动聚焦并全选输入。
- **默认视图（未输入）**：六类分类提示卡（图标 + 可搜字段说明，如「线索：公司 / 联系人 / 手机号」），点击卡片填入该类示例词。静态零状态；不做最近访问（模拟登录下历史会跨角色串数据）。
- **结果行**：实体图标 + 标题（命中词高亮）+ 一行 meta（编号 · 负责人/客户）+ 右侧「↵ 跳转」。
- **键盘**：↑↓ 跨类移动焦点、Enter 执行焦点行、Esc / 点遮罩关闭；无结果时 Enter 无操作。
- 跳转后关闭弹层。

## 8. 消费者走查

任何角色在任意页面 → 顶栏中间看到静态搜索框 → 点击或 ⌘K → 弹层聚焦 → 看到六类提示卡 → 输入「郑州 物联网」→ 项目/线索类各出命中行（关键词高亮、垃圾箱线索不在）→ ↑↓ 选中 → Enter → 跳转 `/projects/:id`，弹层关闭。全程无写操作、无权限差异、无 AI 承诺。

## 9. 决策记录（grill 收束）

| # | 决策 |
|---|---|
| 1 | 范围只切 L1（全局搜索+直达）；斜杠表单 L2 / NL2Action L3 / AI 诊断 L4 不做 |
| 2 | 推翻 2026-08-24 线索派发 grill 的「⌘K 不做」：该决议正名为只约束线索派发列表的局部搜索，全局入口另议且本 PRD 决定做 |
| 3 | 六实体（线索/客户/报价/合同/项目/员工）；死线索排除、作废合同搁置项目保留 |
| 4 | 只读投影 + 六域适配器；不建数据副本；无服务端搜索接口 |
| 5 | 本期不按角色过滤；`opts.actor` 预留接缝 |
| 6 | 视觉收敛为诚实搜索框；AI 品牌全去 |
| 7 | 默认视图 = 六类静态提示卡；不做最近访问 |
| 8 | 匹配：不敏感包含 + 空格 AND + 每类 Top 5 + 无拼音 |
| 9 | 自绘弹层 + 键盘导航；窄屏隐藏 |
| 10 | 挂跨域工具/基础工具；命名「全局搜索」，不用 Copilot |

## 10. 本期不做清单

- ⌘K 之外的快捷键、斜杠快捷表单（/task、/follow、/clue、/trip）
- NL2Action 自然语言建单（α 无真 AI；确定性关键词匹配是假 AI）
- AI 风险诊断 / @项目诊断问答
- 撤销（Undo）：与留痕规则冲突（leadEvents 只增不删、已入账费用作废不删 ADR-0085）
- 最近访问 / 高频实体（模拟登录下历史脏）
- 拼音首字母检索、分词器
- 服务端搜索接口（等数据量或权限需要）
- 搜索结果按角色过滤（等权限矩阵 P0②）
- 交付任务 / 缺陷（Bug Tracker）实体检索--该域尚不存在
