### 二、工作台二（技术人天评估）优化

#### 2.1 键盘导航
- **WASD键直接导航**：只移动焦点，不填入数字
- **方向键+Tab组合**：将当前值填入下一个输入框（保留原有功能）
- **上下键不改变数值**：阻止InputNumber的默认增减行为

#### 2.2 合并与解除合并

##### 合并规则
- 合并时累加被合并子功能的数值
- 合并后的值 = 所有被合并子功能的值之和

##### 解除合并规则
- **寄存值机制**：原值存入第一行作为寄存值
- **红色边框**：寄存行显示红色边框
- **自动扣减**：修改下方行时，从寄存值中自动扣减
- **超支处理**：如果下方值总和大于寄存值，寄存值清零
- **解除条件**：所有解除合并的同列输入框都有值时，红色边框消失

#### 2.3 重置功能
- **"按子功能"重置**：保留原有数值，不会丢失
- **"按模块"打包**：累加所有子功能的值

#### 2.4 底部浮动栏
- **左侧**：工时统计（各岗位人天 + 总人天）
- **右侧**：提交按钮（评估完成，提交 PM 核对）

## 技术要点

### 寄存值机制
```
解除合并时：
1. 原值存入第一行（寄存行）
2. 寄存行显示红色边框
3. 修改下方行时，从寄存值中扣减
4. 如果下方值总和 > 寄存值，寄存值清零
5. 所有解除合并的同列输入框都有值时，红色边框消失
```

### WASD导航
```
- W/↑：向上移动
- S/↓：向下移动
- A/←：向左移动
- D/→：向右移动
- 只移动焦点，不填入数字
```

### 状态机流程
```
阶段1（产品经理）→ 阶段2（技术评估）→ 阶段3（销售报价）→ 阶段4（审批盖章）
      功能清单           人天评估           报价配置           审批流程
```
