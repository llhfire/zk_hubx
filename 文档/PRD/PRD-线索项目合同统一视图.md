> 领域事实源：`HubX/CONTEXT.md` + `HubX/docs/adr/0066`–`0075` + `0097`（及报价域 0001–0065）

## 一、模块概述

### 1.1 定位

同一笔业务在三个模块中的数据联动、状态同步和信息流转。线索、合同、项目是同一事件的三个不同角度描述：

```
线索（销售视角）──签约──→ 合同（管理层视角）──立项──→ 项目（产品经理视角）
     │                      │                       │
  获客·跟进·报价          条款·付款·审批          执行·进度·交付
```

### 1.2 核心业务规则

| 规则 | 说明 |
|------|------|
| 一个线索一个合同 | 一个线索只能关联一个主合同 |
| 签约前可多份报价 | 多份报价独立编号，最后一份有效报价转合同 |
| 签约后可多份补充报价 | 补充报价独立编号，每份对应一份补充合同 |
| 报价审批是内控 | 报价审批通过≠签约；报价已确认≠签约 |
| 签约开启 | 线索进入「合同洽谈 / 已签单」或出现未作废主合同 → 未确认项目（不是报价已确认） |
| 三视角数据联动 | 各对象只在归属模块写入；其他视角只读引用。报价是独立对象 |
| 统计包含补充合同 | 主合同+所有补充合同（内部项目无合同，只做成本统计） |

## 二、三视角数据模型

### 2.1 线索视角（销售）

| 数据项 | 说明 |
|--------|------|
| 线索基本信息 | 客户名称、来源、归属人、状态 |
| 跟进记录 | 跟进历史、下次跟进时间 |
| 报价记录 | 多份报价，独立编号 |
| 合同信息 | 审批后无条件展示 |
| 回款/发票 | 无条件展示 |
| 补充报价/合同 | 展示所有补充记录 |
| 项目进度 | 转合同后可看 |
| 任务/工时 | 转合同后可看 |

### 2.2 合同视角（管理层）

| 数据项 | 说明 |
|--------|------|
| 合同基本信息 | 合同编号、客户、金额、状态 |
| 报价引用 | 当前有效报价（只读） |
| 回款/发票 | 主视图，完整管理 |
| 补充合同 | 主视图，多份补充合同 |
| 项目进度 | 可看 |
| 任务/工时 | 可看 |
| 成本核算 | 可看 |

### 2.3 项目视角（产品经理）

| 数据项 | 说明 |
|--------|------|
| 项目基本信息 | 项目名称、状态、成员、进度 |
| 线索阶段跟进 | 引用线索阶段的跟进记录 |
| 报价引用 | 只读引用 |
| 合同引用 | 只读引用 |
| 回款/发票 | 汇总引用 |
| 任务/工时 | 主视图 |
| 成本核算 | 主视图 |
| 日报 | 主视图 |

### 2.4 项目详情的呈现优先级

- 保留现有顶部控制台、70:30 主侧栏和左右双 Tab，不新建另一张项目工作台。
- 进入项目详情默认查看「项目动态 + 跟进」，首屏优先回答当前阶段、健康信号、最近变化和下一待办；基础档案和报价仍在原 Tab 查看。
- 顶部指标只展示交付进度、剩余工期、工时消耗、合同回款、缺陷质量、风险与阻塞；PM、客户等静态身份留在标题/档案区。
- 项目动态是精选跨域事件流，大事记是其关键子集。普通日报、普通跟进和普通文字编辑不进入。
- 项目动态依 ADR-0097 从合同、回款、确认书、会议纪要和任务事实派生只读投影，不再手工复制同一业务事实。

## 五、三方数据同步规则

### 5.1 签约触发

| 事件 | 线索 | 合同 | 项目 |
|------|------|------|------|
| 报价审批通过+盖章 | 标记报价已盖章 | — | — |
| 报价已确认 | 不改线索状态 | 取得生成主合同资格（向导预填，人工确认） | — |
| 合同审批通过 | 更新状态 | 标记已签约 | 可立项 |
| 线索状态→已签约 | — | — | 自动触发项目立项 |

### 5.2 补充报价/合同触发

| 事件 | 线索 | 合同 | 项目 |
|------|------|------|------|
| 补充报价审批通过+盖章 | 新增补充报价 | — | — |
| 补充报价已确认 | — | 向导生成补充合同（人工确认） | — |
| 补充合同审批通过 | — | 补充合同生效 | 自动更新引用 |

### 5.3 回款/发票联动

| 事件 | 线索 | 合同 | 项目 |
|------|------|------|------|
| 回款登记 | 展示最新回款 | 更新回款状态 | 展示汇总 |
| 开票登记 | 展示最新开票 | 更新开票状态 | 展示汇总 |

## 六、项目立项流程

### 6.1 触发条件

线索进入「合同洽谈 / 已签单」，或出现未作废主合同（草稿也算）→ 自动创建未确认项目。合同批准不负责第一次立项，只启动已指派项目的交付。

### 6.2 待确认项目

| 字段 | 说明 |
|------|------|
| 项目名称 | 自动带入线索名称 |
| 客户名称 | 自动带入 |
| 关联线索 | 自动关联 |
| 关联合同 | 自动关联 |
| 项目状态 | 未确认 |
| 创建时间 | 自动记录 |

### 6.3 确认流程

```
线索进入合同洽谈/已签单，或主合同创建
    ↓
自动创建未确认项目（产品经理默认看不见）
    ↓
管理员确认并指定产品经理 → 项目变为未开始
    ↓
合同批准 → 已指派项目进入进行中（交付启动）
```

### 6.4 确认规则

- 确认人：管理员（必须指定产品经理）
- 确认后：项目变为未开始，该产品经理才看得见
- 确认前：未确认项目只在管理员待确认队列
- 退回线索：管理员可退未确认，或未开始且无未作废主合同；线索改回方案报价。进行中或仍有未作废主合同不能退

## 七、补充报价与补充合同

### 7.1 流程

```
签约后需要变更
    ↓
销售创建补充报价
    ↓
走完整报价流程（评估→报价→审批→盖章）
    ↓
补充报价已确认
    ↓
向导生成补充合同（人工确认）
    ↓
补充合同走合同审批
    ↓
归档后变更额计入有效标的额；项目侧只读引用更新
```

### 7.2 补充合同数据来源

| 数据项 | 来源 |
|--------|------|
| 客户信息 | 从主合同带入（只读） |
| 补充报价内容 | 从补充报价带入（只读） |
| 补充金额 | 从补充报价带入 |
| 补充条款 | 向导预填后可改 |

### 7.3 统计规则

- 合同统计 = 主合同 + 所有补充合同
- 回款统计 = 主合同回款 + 所有补充合同回款
- 成本统计 = 项目维度汇总（含主合同和补充合同）

## 八、数据一致性校验

| 校验项 | 规则 | 提示方式 |
|--------|------|----------|
| 合同金额 vs 报价金额 | 应相等 | 黄色警告 |
| 补充合同金额 vs 补充报价金额 | 应相等 | 黄色警告 |
| 回款总额 vs 合同金额 | 不应超过 | 黄色警告 |
| 项目成本 vs 合同金额 | 不应超过（内部项目无合同额，不做此项） | 黄色警告 |
| 补充合同累计 vs 原合同金额 | 可超过，需预警 | 黄色警告 |

**所有校验仅提醒，不卡流程。**

## 九、状态机

### 9.1 线索状态（沿用现网，不另造一套）

```
[未联系] → [未接通] → [初步沟通] → [需求调研] → [方案报价] → [合同洽谈] → [已签单]
                                                                  ↓
                                                              [已终止]
```

报价进度只在报价单上，不在线索状态里做「待报价 / 报价中 / 待签约」。

### 9.2 合同状态（沿用现网）

```
[草稿] → [审批中] → [待寄出] → [待回寄] → [已归档]
     ↘         ↘           ↘           ↘
                    [已作废]
审批中可驳回/撤回 → 草稿
```

没有「已签约 / 执行中」合同状态。履约看回款和项目。

### 9.3 项目状态（沿用现网）

```
[未确认] → [未开始] → [进行中] → [验收中] → [已完成]
                ↘ 搁置 / 延迟 / 催款中
```

退回线索是管理员动作，不是项目状态。

### 9.4 三方状态联动

| 线索状态 | 合同状态 | 项目状态 | 触发条件 |
|----------|----------|----------|----------|
| 方案报价 | — | — | 报价进行中（以报价单状态为准） |
| 合同洽谈 / 已签单 | 可无或草稿 | 未确认 | 签约开启 |
| 合同洽谈 / 已签单 | 审批中 | 未开始 | 管理员已指派产品经理，合同未批准 |
| 已签单 | 待寄出及之后 | 进行中 | 合同批准且项目已指派 |
| 已签单 | 已作废 | 搁置 | 主合同作废；新合同批准后再开工 |
