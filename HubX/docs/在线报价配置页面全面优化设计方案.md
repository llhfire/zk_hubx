# 在线报价配置页面（Stage 3）全面优化设计方案

> **文档定位**：数据流转方式中「工作台三 · 在线报价配置」（`Stage3WebAutomation.tsx`）的标杆化重构方案。  
> **指导原则**：先写方案、不动代码；以销售商务精算与成单决策为中心，消灭视觉冗长与割裂，提升信息密度与核算效率。

---

## 一、现状痛点分析与重构动机

当前在数据流转模式中，销售进入「阶段三 · 在线报价配置」承担着核算成本、调整毛利、敲定商务条款与提交内审的核心职责。但现有页面存在以下核心痛点：

### 1. 缺乏全局商务驾驶舱，视线来回奔波
- **现状**：页面采用单一垂向流依次堆叠了 7 个 Card。
- **痛点**：销售最关心的三大商业决策指标（**最终对外总价**、**综合人力毛利率**、**项目周期与交付节点**）被埋在最底部的第 6 个 Card 中。销售在上方调整单价、添加增项或出差时，必须反复滚屏到底部确认总价与毛利变动，体验极其割裂。

### 2. 阶段一/二的功能工时表过于沉重，霸占 60% 首屏高度
- **现状**：Card 2 把所有终端、模块与子功能的工时原样展开，行数常达几十甚至上百行。
- **痛点**：销售在该阶段关注的是**岗位整体工时与基准人天单价**，而非逐行查看每个子功能。几百行的表身导致页面被无限拉长，信息密度过低。

### 3. 岗位人天单价编辑交互隐蔽生硬
- **现状**：单价设置隐藏在庞大表格的表头中，以极细的下划线标记，点击后弹出窄小的输入框。
- **痛点**：无法直观概览各个技术角色的投入成本结构，缺乏全局调价视野（例如快速上浮/下浮或横向对比）。

### 4. 付款方式缺乏快捷模版预设
- **现状**：付款条款需手动逐行修改阶段名称与输入百分比，若总和不等于 100% 仅在底部给出红字提示。
- **痛点**：行业常用的“标准 3:3:3:1”、“敏捷 5:3:2”、“两期 5:5”没有一键套用预设，输入效率低。

### 5. 内审阻断与校验提示严重滞后
- **现状**：拦截提交的错误项（如发票未选、付款未达 100%、模板缺字段等）仅在页面最底部弹出 Alert。
- **痛点**：销售不知道当前报价是否合规，必须滑动到最下方点击提交失败后才知道缺少什么。

## 二、目标架构与设计原则

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        数据流转 · 工作台三 · 在线报价配置                                  │
├──────────────────────────────────────────────────────────────┬─────────────────────────┤
│                     左侧 72% 商务成本与条款配置区              │   右侧 28% 商务驾驶舱   │
├──────────────────────────────────────────────────────────────┼─────────────────────────┤
│ 1. 签约主体与基础商务信息条                                    │ 💰 项目总报价 (高亮大字) │
├──────────────────────────────────────────────────────────────┤ 📈 综合人力毛利率 (阶梯) │
│ 2. 研发成本与岗位费率调优器 (紧凑卡片 + 功能清单折叠抽屉)      │ ⏱️ 交付工期与预计完工日 │
├──────────────────────────────────────────────────────────────┤ ─────────────────────── │
│ 3. 销售增项岗位 (PMO/驻场运维/汇报增项)                        │ 🧱 成本积木多维穿透构成 │
├──────────────────────────────────────────────────────────────┤ ─────────────────────── │
│ 4. 交付履约配置 (出差地点 / 现场驻场服务)                      │ 📋 内审体检清单 (Check) │
├──────────────────────────────────────────────────────────────┤ ─────────────────────── │
│ 5. 外部自费项目 (云资源/短信/第三方接口代采，不计我方营收)     │ 📄 报价单 1:1 预览入口   │
├──────────────────────────────────────────────────────────────┤ 🚀 提交审批主行动按钮   │
│ 6. 商务结算条款 (付款计划预设模版 3:3:3:1、税票与质保)         │                         │
└──────────────────────────────────────────────────────────────┴─────────────────────────┘
```

### 核心设计原则：
1. **72:28 双栏分工，商务指标常驻可见**：左侧负责精细化录入与调参，右侧以 Sticky 浮动面板实时响应呈现总价、毛利率、成本构成与内审合规体检清单；
2. **渐进式展开（Progressive Disclosure）**：功能工时采用“岗位费率汇总卡 + 功能清单抽屉/折叠”呈现，首屏高度降低 60%；
3. **成本积木模块化**：严格区隔【研发人天】、【商务增项】、【差旅驻场】与【客户自费】，商务边界清晰透彻；
4. **一键预设赋能**：内置常见商务付款比例模版与费率预设，减少 80% 的重复打字。

## 三、各核心模块重构细化方案

### 模块 1：签约主体与项目关键信息条（顶栏）
- **布局**：采用轻量横向通栏（Banner），背景为浅灰高质感背景，避免大 Card 浪费空间。
- **要素**：
  - 签约与落款主体（Select 下拉，关联集团 5 家法人主体，显示统一社会信用代码与简称）；
  - 关联合同模式标识（标准首版报价 / 增补变更报价）；
  - 若为增补报价，支持输入本次变更增减额（可为负）。

### 模块 2：研发成本与岗位费率调优器（核心升级）
- **消灭冗长表格霸屏**：
  - **顶部岗位费率卡片网格**：横向并排呈现本次评估包含的各角色（如：前端开发、后端开发、UI 设计师、测试工程师、系统架构师）；
  - **卡片内要素**：
    - 岗位名称与图标；
    - 评估人天（如 `15.0 天`）；
    - 日成本单价调节器（`¥800/天`，支持直接点击输入或 ±50 快捷微调）；
    - 岗位小计金额（如 `¥12,000`）；
  - **功能明细折叠/弹层**：
    - 提供「查看具体功能工时明细（共 24 项）」折叠面板或侧边抽屉；
    - 默认收起，销售需要对齐具体需求时可一键展开只读核对，不再阻挡首屏主视线。

### 模块 3：销售增项岗位配置（加项利器）
- **业务场景**：销售根据客户特定诉求（如每周驻场例会汇报、独立 PMO 协调、系统安全等保支持）添加的商务加项。
- **UI 优化**：
  - 优化网格对齐，提供预设加项标签（一键填入：`PMO 项目管理`、`驻场联调支持`、`系统等保配合`）；
  - 输入人数、天数、日单价，动态计算小计并展示毛利贡献；
  - 明确标注：销售增项计入项目总价，但不计入技术人天评估范围。

### 模块 4：交付实施配置（出差与驻场整合卡片）
- **整合收纳**：
  - 将原本分散的出差和驻场合并为「交付与履约服务」卡片，以左右或上下分块联动；
  - **出差地点配置**：
    - 支持一键快速添加地点；
    - 字段包含：城市地点、人数、天数、往返交通费、住宿单价、差旅补贴；
    - 实时计算差旅总额；
  - **驻场技术服务**：
    - 字段包含：服务地点、人数、天数、日技术服务费；
    - 实时计算驻场总额。

### 模块 5：外部自费项目清单（隔离非营收项）
- **业务定位**：云服务器（阿里云/腾讯云）、对象存储 OSS、微信认证费、短信包、电子发票税盘等。
- **明确边界**：
  - 用显著的提示 Tag 标明：「自费项目由客户自行采购或我司代采，按实际发票报销，**不计入我方研发总价与毛利核算**」；
  - 数据与标准报价单 PDF 的 Page 5~6 严格联动。

### 模块 6：商务结算条款与付款模版（付款计划智能化）
- **预设模版快捷套用**：
  - 增加「快捷模版」下拉框：
    1. **标准项目 (30% - 30% - 30% - 10%)**：预付款 30%、阶段验收 30%、交付上线 30%、质保金 10%；
    2. **敏捷交付 (50% - 30% - 20%)**：预付款 50%、上线验收 30%、质保金 20%；
    3. **中大型定制 (40% - 30% - 20% - 10%)**：合同生效 40%、原型确认 30%、上线终验 20%、质保 10%；
    4. **两期交付 (50% - 50%)**：预付款 50%、验收合格 50%；
  - 点击任一模版，自动替换现有付款节点与百分比；
- **比例合计状态条**：
  - 动态计算合计比例，若非 100% 显示醒目差额提示（如：`当前合计 90%，还差 10%`）；
  - 显示节点折合具体金额（如 `30% (¥57,000)`）。
- **发票与质保**：
  - 增值税专票（6%）/ 增值税普票下拉；
  - 质保期选择（1年 / 2年 / 3年）。

## 四、右侧常驻商务驾驶舱（Sticky 28% 侧边栏）

右侧为贯穿全阶段配置的“商务大脑”，包含三大核心板块：

### 1. 核心商业指标卡
- **项目总报价**：深色/品牌蓝渐变大背景，呈现格式化金额（如 `¥ 190,000`）；
- **综合开发人力毛利率**：
  - >= 45%：绿色 Tag（健康优良）；
  - 35% ~ 45%：蓝色 Tag（符合底线）；
  - < 35%：橙红 Tag（低于公司底线 35%，标明可能需要特批审批）；
- **工期与交付节点**：
  - 评估工期：`25 工作日`；
  - 开发人天：`40.0 人天`；
  - 预计交付日期：`2026-10-15`（根据工作日算法实时联动计算）。

### 2. 多维成本积木穿透环图
- 以色彩柱状堆叠条直观展示：
  - 🟦 技术基础成本（如 70%）；
  - 🟪 销售商务增项（如 15%）；
  - 🟧 交付差旅驻场（如 15%）；
- 鼠标悬浮查看具体分项金额与占比。

### 3. 内审体检核对清单（Pre-flight Checklist）
- 实时进行 4 项合规体检：
  - [x] 签约主体已确认
  - [x] 付款方式比例合计等于 100%
  - [x] 技术人力成本已评估
  - [x] 毛利率达到底线要求（若低于 35% 标注黄灯特批提示）
- 只有全部绿灯通过时，主提交按钮才激活可用。

### 4. 报价单预览与提交动作区
- **「在线审阅与修改报价单」快捷入口**：点击直接呼出 6 页 A4 模态工作台；
- **「提交审批」大按钮**：支持一键提交，自动固化 `pricingSummary` 快照并流转进入审批阶段。
