# 线索详情页“报价”Tab PRD

| 项目 | 内容 |
| --- | --- |
| 版本 | V1.0 |
| 日期 | 2026-07-27 |
| 适用页面 | 线索详情页、项目详情页中复用的“报价”Tab |
| 模块目标 | 基于完整成本配置完成报价、沉淀多版本报价记录，并通过总经理审批形成可追溯的报价历史。 |

## 1. 模块范围

本模块包含以下能力：

1. 新增报价及编辑最新报价。
2. 报价系统配置、实时成本计算和报价汇总。
3. 完善报价资料并生成一条报价版本记录。
4. 报价历史查看、展开明细、附件预览和下载。
5. 技术评估文件、报价单补传。
6. 总经理单节点审批及审批意见留痕。
7. 报价附件自动归集至该线索的“资料”Tab。

不在本期范围内：报价记录删除、报价单在线编辑、多人会签审批、审批流配置。

## 2. 核心业务规则

1. 一条报价记录代表一次完整报价快照；新增报价或编辑报价均生成新记录，不覆盖历史记录。
2. 报价记录按创建时间倒序展示，最新报价置顶；列表默认收起详情。
3. 只有最新报价可编辑、补传审批附件或提交审批；历史报价只可查看。
4. 编辑最新报价时，读取该报价原有的报价系统配置；提交后生成一条新的报价记录并成为最新报价。
5. 报价审批为“总经理”单节点：提交后显示“总经理审批中”，同意后为“已审核”，拒绝后为“已驳回”。
6. 技术评估文件和报价单均已上传后，才允许提交审批。
7. 报价系统记录在报价资料提交时生成，并与该报价记录关联；报价系统文件不在报价详情中展示。
8. 任何由报价模块上传或生成的文件，都必须自动归集到该线索的“资料”Tab，并保留来源为“报价”。
9. “新增报价”只作为首条报价的创建入口；已有报价记录后隐藏该按钮，后续通过编辑最新报价创建新版本。

## 3. 页面结构

### 3.1 报价历史区域

- 标题：`报价历史`
- 标题右侧：`共 N 条`
- 右上角按钮：仅在无任何报价记录时显示`新增报价`；已有报价记录时隐藏。
- 空状态：`暂无报价记录`

每条报价记录包含：

| 区域 | 内容 |
| --- | --- |
| 标题 | 报价名称；最新一条额外显示“最新报价”标签。 |
| 状态 | 报价状态、审批状态。 |
| 核心信息 | 报价金额、创建时间、报价人。 |
| 操作区 | 左侧放当前记录可执行的操作，右侧固定为“展开详情 / 收起详情”。 |
| 展开详情 | 预计周期、技术评估人、报价说明、报价系统记录、技术评估文件、报价单、审批记录。 |

展示要求：

1. “预计周期、技术评估人、报价说明”置于报价系统记录上方。
2. 报价系统记录、技术评估文件、报价单归为同一附件区域，每项独占一行，标题、文件名、预览/下载操作对齐。
3. 技术评估文件和报价单未上传时，展开详情中不显示对应行。
4. 文件名可点击预览；下载使用下载图标；不显示小眼睛图标。
5. 审批记录为空时，不显示审批记录区域。

### 3.2 状态与操作

| 审批状态 | 最新报价可见操作 | 历史报价可见操作 |
| --- | --- | --- |
| 未提交审批，缺技术评估文件 | 上传技术评估文件；如同时缺报价单，也显示上传报价单。 | 展开详情。 |
| 未提交审批，缺报价单 | 上传报价单；如同时缺技术评估文件，也显示上传技术评估文件。 | 展开详情。 |
| 未提交审批，附件齐全 | 编辑、提交审批。 | 展开详情。 |
| 总经理审批中 | 编辑、审批同意、审批拒绝。 | 展开详情。 |
| 已审核 | 展开详情。 | 展开详情。 |
| 已驳回 | 展开详情。 | 展开详情。 |

说明：

- “提交审批”仅在技术评估文件和报价单均存在时显示。
- “审批同意”“审批拒绝”均需先弹出审批意见输入框，意见为必填。
- “编辑”不会原地修改当前记录，而是创建新的报价版本。

## 4. 新增与编辑报价流程

```mermaid
flowchart LR
    A[新增报价 / 编辑最新报价] --> B[报价系统配置]
    B --> C[报价汇总]
    C --> D[完善报价资料]
    D --> E[生成报价系统记录]
    E --> F[创建新的报价记录]
    F --> G[补传技术评估文件和报价单]
    G --> H[提交总经理审批]
```

### 4.1 报价系统

点击“新增报价”后，第一步打开标题为“报价系统”的弹窗。报价系统由六个步骤组成：

1. 前端配置
2. 后端配置
3. 其他岗位
4. 出差驻场
5. 其他成本
6. 报价汇总

弹窗底部固定提供：`取消`、`上一步`、`下一步`。在报价汇总页点击“下一步”前，项目总报价必须大于 0。

顶部持续展示四项实时汇总：人力成本、差旅与驻场、其他成本、报价总额。

### 4.2 前端配置

副文本：`选择前端平台，每个平台可添加多个角色端（如用户端、商家端），并选择开发语言`。

| 配置项 | 规则 |
| --- | --- |
| 前端平台 | 微信小程序、支付宝小程序、抖音小程序、iOS APP、Android APP、鸿蒙 APP、H5 移动端、PC Web 端、桌面应用、iPad 端、Android 平板端。 |
| 选择方式 | 平台列表每行展示 6 项；每一项的标题与右侧勾选框同行、两端对齐。 |
| 角色端 | 勾选平台后默认生成一条角色端，可继续新增多个角色端，例如用户端、商家端、司机端、配送端。 |
| 每个角色端字段 | 角色名称、开发语言/框架、人数、天数、日均成本、小计。 |
| 默认技术栈 | 小程序支持原生开发、Taro、Uni-app；移动端/平板端按平台支持 Swift、Kotlin、Java、React Native、Flutter、ArkTS；Web 支持 Vue、React、Angular；桌面应用支持 Electron、Tauri。 |
| 自定义技术栈 | 技术栈列表最后一项为“自定义”；仅勾选“自定义”后展示自定义技术栈名称和日均成本输入项。 |

| 选择方式 | 服务列表每行展示 6 项；每一项的标题与右侧勾选框同行、两端对齐。 |
| 每项服务字段 | 角色名称、开发语言/框架、人数、天数、日均成本、小计。 |

| 驻场配置 | 驻场人数、驻场天数、住宿费、餐饮补贴、交通补贴、驻场费用小计。 |

### 4.6 其他成本

| 成本分类 | 配置项 |
| --- | --- |

| 销售成本 | 销售提成比例、其他销售费用；销售提成自动计算。 |
| 项目运营成本 | 客户培训费、文档制作费、版本更新费。 |
| 第三方服务成本 | 云服务器年费、域名费用、SSL证书费、短信服务费、推送服务费、支付通道费、第三方接口费、软件许可证费。 |
| 硬件设备成本 | 服务器采购费、办公设备费。 |

### 4.7 报价汇总

报价汇总页实时展示：

1. 总人天、总人数、预计工期、项目总报价。
2. 人力成本明细。
3. 出差驻场成本明细。
4. 其他成本明细。
5. 大字号“项目总报价”金额。
6. 人力、差旅、其他成本占项目总报价的百分比。

计算规则：

| 项目 | 计算方式 |
| --- | --- |
| 单条人力成本 | 人数 × 天数 × 日均成本。 |
| 出差交通费 | 单程交通费 × 2 × 出差人数 × 出差次数。 |
| 出差住宿费 | 住宿费 × 每次天数 × 出差人数 × 出差次数。 |
| 出差补贴 | （餐饮补贴 + 其他补贴）× 每次天数 × 出差人数 × 出差次数。 |
| 驻场住宿费 | 月住宿费 × 驻场人数 × 向上取整（驻场天数 / 30）。 |
| 驻场餐饮补贴 | 餐饮补贴 × 驻场天数 × 驻场人数。 |
| 驻场交通补贴 | 月交通补贴 × 驻场人数 × 向上取整（驻场天数 / 30）。 |
| 销售提成 | （人力成本 + 出差成本 + 驻场成本 + 固定其他成本）× 销售提成比例。 |
| 项目总报价 | 人力成本 + 出差成本 + 驻场成本 + 其他成本。 |

## 5. 完善报价资料

从报价汇总点击“下一步”后，打开“完善报价资料”弹窗。

| 字段 | 控件与来源 | 规则 |
| --- | --- | --- |
| 报价金额 | 金额输入框 | 默认带入项目总报价；必填，可按业务实际调整。 |
| 报价人 | 员工下拉列表 | 从员工列表读取；必填；新增报价时默认选择当前登录用户，支持手动修改。 |
| 预计周期 | 文本输入框 | 必填；仅允许输入正整数，输入框最右侧固定显示“天”，右侧间距 10px；默认带入报价汇总的预计天数。 |
| 技术评估人 | 人员多选下拉列表 | 必填；从可选技术评估人员读取，支持选择多位人员并以“、”展示。 |
| 报价信息 | 报价汇总表格 | 展示本次报价系统的总人天、总人数、预计工期、项目总报价及三类成本明细。 |
| 报价说明 | 多行文本框 | 最多 500 字。 |

以下字段不在“完善报价资料”弹窗中展示：报价系统文件、技术评估文件、报价单。

点击“提交”后：

1. 保存报价系统配置快照、报价汇总结果和报价资料。
2. 生成报价系统记录并关联到该报价记录，文件名为`[系统名称]报价单YYYYMMDD+时间戳后6位.png`。
3. 新增一条审批状态为“未提交审批”的报价记录。
4. 如果为编辑场景，旧记录保持不变，新记录成为最新报价。

## 6. 附件与预览

| 附件 | 产生方式 | 展示位置 | 操作 |
| --- | --- | --- | --- |
| 报价系统记录 | 提交报价资料时自动生成。文件名为`[系统名称]报价单YYYYMMDD+时间戳后6位.png`。 | 展开详情的附件区域。 | 打开链接、下载。 |
| 技术评估文件 | 报价记录创建后由最新记录补传。 | 有文件时展示。 | 文件名预览、下载。 |
| 报价单 | 报价记录创建后由最新记录补传。 | 有文件时展示。 | 文件名预览、下载。 |

文件规则：

1. 报价系统文件不在展开详情中展示。
2. 最新报价缺少技术评估文件或报价单时，操作区显示对应的上传按钮；上传后立即更新记录状态。
3. 技术评估文件支持 PDF、DOC、DOCX、XLS、XLSX、ZIP、RAR；报价单支持 PDF、DOC、DOCX、XLS、XLSX。
4. PDF、图片可在线预览；其他格式可接入在线预览，无法预览时保留下载入口。
5. 文件上传、报价系统记录生成后，需要自动写入该线索“资料”Tab 的统一文件索引，来源标签为“报价”。
6. 最新且未完成审批的报价中，技术评估文件和报价单的下载按钮左侧显示删除图标；删除后移除该文件行，并在操作区重新显示对应上传按钮。

## 7. 审批记录

审批记录仅在实际存在审批节点时展示，按流程顺序显示：

| 节点 | 记录内容 |
| --- | --- |
| 发起申请 | 申请人、申请时间、申请状态。 |
| 总经理审批 | 审批人、待处理/已通过/已驳回状态、操作时间、审批意见或驳回原因。 |

审批操作：

1. 点击“提交审批”后，创建“发起申请”和“总经理审批”两个节点。
2. 点击“审批同意”或“审批拒绝”后必须填写审批意见。
3. 审批同意后，该报价状态变为“已审核”；审批拒绝后变为“已驳回”。
4. 已审核、已驳回的报价不再显示提交审批按钮。

## 8. 交互与异常处理

1. 点击新增报价，先进入报价系统，不直接打开报价资料表单。
2. 报价金额必须大于 0；报价人不能为空；项目总报价为 0 时不得进入报价资料页。
3. 文件上传失败时不应将文件标记为已上传，也不得出现提交审批按钮。
4. 文件上传成功、审批提交成功、审批决策成功后刷新当前报价记录和资料Tab文件索引。
5. 报价历史始终默认收起；用户切换线索或刷新数据后，不保留展开状态。
6. 不显示编辑、删除的图标按钮；通过“编辑”文字按钮进入最新报价的配置流程。

## 9. 验收清单

- [ ] 新增报价可完成六个配置步骤，所有汇总金额实时正确变化。
- [ ] 前端/后端平台每行显示 6 项，勾选框位于标题右侧；自定义技术栈未选中时输入项隐藏。
- [ ] 编辑报价会生成新记录，旧记录的配置、金额、附件和审批记录不被改写。
- [ ] 报价历史倒序展示，最新记录唯一且置顶，页面初次打开时全部收起。
- [ ] 技术评估文件和报价单未齐时不显示提交审批，仅显示缺失文件对应的上传按钮。
- [ ] 两个文件齐全后显示“提交审批”；进入审批后显示“审批同意”“审批拒绝”。
- [ ] 审批意见必填；同意后为“已审核”，拒绝后为“已驳回”，审批记录正确留痕。
- [ ] 报价系统记录按命名规则生成且可打开、下载；技术评估文件和报价单可预览、下载。
- [ ] 报价产生的所有文件均可在该线索“资料”Tab 中找到，并显示“报价”来源。
