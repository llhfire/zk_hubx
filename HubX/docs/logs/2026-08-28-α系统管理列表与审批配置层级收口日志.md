# α 系统管理列表与审批配置层级收口日志

## 本轮范围

仅调整 α 原型，不改 β Web 与 API。以“我的线索列表”的页面节奏为基准，收口系统日志、意见反馈管理、审批模板和业务审批配置四类页面。

## 完成内容

- `SystemLog` 接入 `PageShell`、`PageHeader`、`ProcessMetricGrid` 和 `FilterBar`，统一为“页头 → 指标 → 日志页签 → 筛选 → 结果”的列表结构。
- 操作日志与登录日志由占位搜索改为实时筛选，支持关键词、模块、状态和日期组合条件；补齐结果计数、无结果空态和一键清除。
- `FeedbackManagement` 统一页头、处理指标、筛选、结果反馈与空态；保留详情、处理和附件下载流程，并为图标操作补充无障碍名称。
- 审批模板、业务审批配置接入共享页头与三级面包屑。页面会按入口切换为“审批管理 → 审批中心 → 当前页”或“系统管理 → 系统配置 → 当前页”。
- 表格统一横向滚动边界，窄屏筛选项改为整行排列，避免页面级横向溢出。

## 验证结果

- 模型单测：`systemAdministrationListModel.test.ts`，4/4 通过；全量 Vitest 为 85 个文件、977 项测试全部通过。
- α 构建：`npm run build` 通过；仅保留仓库既有的 Gantt 注释和大 chunk 提示。
- 浏览器验收：系统日志关键词筛选、登录页签、无结果与清除筛选通过；意见反馈 2 条临时样本的指标、筛选与空态通过，测试后已恢复原数据。
- 路由验收：`/approvals/templates`、`/system/workflow`、`/approvals/business`、`/system/bizapproval` 的上下文面包屑正确。
- 1200px 与 760px 视口均无页面级横向溢出，页面标题为统一 20px。
