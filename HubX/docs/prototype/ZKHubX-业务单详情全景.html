软件外包成本模型（驻场-二线城市）

ID: cost-software-outsourcing-tier2 · 版本: 20260801002
适用场景：
  • 软件定制开发项目 / 驻场或半驻场模式
  • 二线城市基准（成都、武汉、南京等），周期 1~6 个月
核心计算公式 (5大分类)：
• 总完工成本 (EAC) = 人工成本 + 差旅成本 + 推广成本 + 商务成本 + 第三方费用
• 人工成本 = Σ(各岗位人天 × 岗位日薪)
• 商务成本 ≤ commercialCap (¥25,000 上限管控)
• 最低谈判底线价 = EAC / (1 − 目标利润率)
局限性与风险控制：

若客户在中期发生重大需求蔓延，需发起变更补充报价与补充合同，重新核算 EAC 完工估算，避免击穿利润率底线。
