## 2. 需求背景

项目推进过程中会持续发生需求评审、方案沟通、进度同步、范围确认、验收等会议。当前会议内容主要通过即时通信、个人文档或本地文件分散保存，缺少统一的项目维度归档，后续难以追溯会议结论、参会人员、录音和会议资料。

本需求在项目详情页右侧新增“会议纪要”Tab，以项目为归属记录每次会议沟通内容，并通过按会议时间倒序排列的时间流集中展示。

## 3. 产品目标

1. 统一沉淀项目会议主题、参会人员、会议结论及附件。
2. 支持快速查看项目历史沟通记录，降低信息追溯成本。
3. 同时覆盖公司内部员工和客户等外部参会人员。
4. 将会议录音、会议资料与会议纪要建立明确关联。
5. 保证长会议纪要在列表中简洁展示，同时支持查看完整内容。

## 4. 适用范围

### 4.1 本期范围

* 项目详情页右侧新增“会议纪要”Tab。
* 按会议时间倒序显示会议记录时间流。
* 新增会议纪要。
* 内部参会人员工多选。
* 外部参会人手动录入。
* 会议纪要长文本录入与十行折叠。
* 会议录音多附件上传与下载。
* 会议资料多附件上传与下载。

### 4.2 本期不包含

* 会议纪要审批。
* 会议邀请、日历通知和参会提醒。
* 在线录音、实时转写和 AI 自动总结。
* 会议纪要版本管理。
* 评论、点赞和多人协同编辑。
* 会议纪要跨项目复制或移动。
* 会议附件在线预览和音频在线播放。

| 项目成员   | 查看所属项目的会议纪要；按权限新增会议记录 |
| 项目负责人  | 查看和新增项目会议纪要           |
| 项目管理人员 | 查看权限范围内项目的会议纪要        |

## 6. 页面入口与导航

### 6.1 页面入口

入口路径：`项目管理 → 项目详情 → 右侧 Tab → 会议纪要`。

### 6.2 Tab 位置

“会议纪要”位于“合同记录”右侧、“演示”左侧。

右侧 Tab 顺序如下：

```text
跟进 → 报价 → 合同记录 → 会议纪要 → 演示 → 资料 → 出差 → 报销
```

## 7. 会议纪要列表

### 7.1 展示方式

* 使用纵向时间流展示会议记录。
* 按会议时间倒序排列，最新会议显示在最上方。
* 每条记录直接显示在时间流中，不增加外层卡片背景、边框或色块。
* 相邻会议记录之间的垂直间距为 30px。
* 没有会议记录时显示空状态文案“暂无会议纪要”。

### 7.2 单条记录内容

单条会议记录按照以下顺序展示：

1. 会议主题。
2. 会议时间、记录人。
3. 参会人：内部员工、外部人员。
4. 会议纪要正文。
5. 会议录音。
6. 会议资料。

### 7.3 参会人展示

* 内部员工使用强调色标签展示。
* 外部人员使用普通标签展示，并在姓名后增加“（外部）”。
* 多个参会人自动换行，不撑开右侧面板。

### 7.4 长文本折叠

* 会议纪要正文默认最多显示 10 行。
* 正文未超过 10 行时，不显示展开或收起按钮。
* 正文超过 10 行时，在正文下方显示“展开”。
* 点击“展开”后显示完整正文，按钮文案变为“收起”。
* 点击“收起”后恢复最多 10 行的展示状态。
* 展开状态仅影响当前会议记录，不影响其他记录。

### 7.5 附件展示

* “会议录音”和“会议资料”标签使用固定宽度，文字不得换行。
* 每个附件显示文件图标和文件名。
* 点击附件执行下载。
* 会议录音不提供在线播放按钮。
* 当前记录没有对应附件时，不显示该附件分组。

## 8. 新增会议纪要

### 8.1 操作入口

会议纪要 Tab 右上角显示“新增记录”按钮。点击后打开“新增会议纪要”弹窗。

### 8.2 表单字段

| 字段    | 类型      | 必填 | 规则                               |
| ----- | ------- | -- | -------------------------------- |
| 会议主题  | 单行文本    | 是  | 输入会议名称或核心议题                      |
| 会议时间  | 日期时间选择器 | 是  | 精确到 30 分钟，格式为 `YYYY-MM-DD HH:mm` |
| 内部参会人 | 员工多选    | 否  | 数据来源于员工管理，排除已离职员工                |
| 外部参会人 | 标签输入    | 否  | 输入名称后按 Enter 生成标签，可连续录入多人        |
| 会议纪要  | 长文本     | 是  | 最多 5000 字                        |
| 会议录音  | 多附件上传   | 否  | 仅接受音频格式                          |
| 会议资料  | 多附件上传   | 否  | 接受文档、表格、演示文稿、图片和压缩包              |

### 8.3 会议时间规则

* 使用日期时间选择控件，不允许仅通过普通文本输入完成选择。
* 分钟选项以 30 分钟为步长，仅提供 `00` 和 `30`。
* 默认值为当前日期与时间，并向下对齐到最近的半小时。
* 保存格式为 `YYYY-MM-DD HH:mm`。
* 列表排序以会议时间为准，不以创建时间为准。

### 8.4 内部参会人

* 支持搜索员工姓名。
* 支持多选和清空。
* 下拉选项显示员工姓名、部门和职位。
* 已离职员工不进入新增表单的可选范围。
* 已保存记录中的历史员工信息不得因员工离职而丢失。

### 8.5 外部参会人

* 使用纯标签输入框，不显示候选下拉列表。
* 输入姓名后按 Enter，将当前输入内容转为人员标签。
* 生成标签后输入框保持可用，可继续录入下一位人员。
* 支持删除已录入的外部人员标签。
* 输入框失去焦点时，可保存尚未按 Enter 的有效文本。
* 自动过滤首尾空格和空字符串。
* 同一条会议记录中，完全相同的外部人员名称不得重复保存。

### 8.6 会议纪要

* 支持多行长文本。
* 建议记录会议结论、待办事项、责任人和时间节点。
* 保留用户输入的换行格式。
* 为空时不得提交。

### 8.7 会议录音

* 支持多文件选择。
* 支持格式：`.mp3`、`.wav`、`.m4a`、`.aac`、`.ogg`、`.flac`。
* 上传列表显示文件名和删除操作。
* 不显示播放按钮、预览按钮、开始上传按钮或圆形进度操作按钮。
* 文件上传成功后，与当前会议记录建立关联。

### 8.8 会议资料

* 支持多文件选择。
* 支持格式：`.pdf`、`.doc`、`.docx`、`.xls`、`.xlsx`、`.ppt`、`.pptx`、`.jpg`、`.jpeg`、`.png`、`.zip`、`.rar`。
* 上传列表显示文件名和删除操作。
* 不显示播放按钮、预览按钮、开始上传按钮或圆形进度操作按钮。
* 文件上传成功后，与当前会议记录建立关联。

### 8.9 提交与取消

* 点击“确定”时校验必填字段和附件格式。
* 校验通过后创建会议记录，关闭弹窗，并将新记录插入时间流的正确位置。
* 保存成功提示“会议纪要已新增”。
* 点击“取消”关闭弹窗，不保存当前输入。
* 再次打开弹窗时，不保留上次已取消的数据。

## 9. 排序与状态规则

### 9.1 排序

```text
会议时间倒序 → 会议记录创建时间倒序
```

当两条记录的会议时间完全相同时，后创建的记录显示在前。

### 9.2 空状态

| 场景         | 处理方式       |
| ---------- | ---------- |
| 项目没有会议记录   | 显示“暂无会议纪要” |
| 没有内部参会人    | 仅展示外部参会人   |
| 没有外部参会人    | 仅展示内部参会人   |
| 没有任何参会人    | 不显示空参会人标签  |
| 没有会议录音     | 不显示会议录音分组  |
| 没有会议资料     | 不显示会议资料分组  |
| 纪要不超过 10 行 | 不显示展开/收起按钮 |

## 11. 接口建议

| 方法     | 接口                                   | 说明          |
| ------ | ------------------------------------ | ----------- |
| `GET`  | `/api/projects/{projectId}/meetings` | 获取项目会议纪要列表  |
| `POST` | `/api/projects/{projectId}/meetings` | 新增会议纪要      |
| `POST` | `/api/files`                         | 上传会议录音或会议资料 |
| `GET`  | `/api/files/{fileId}/download`       | 下载会议附件      |

列表接口默认按照 `meetingTime DESC, createdAt DESC` 返回。

## 12. 校验与异常处理

| 场景        | 处理规则             |
| --------- | ---------------- |
| 会议主题为空    | 提示“请填写会议主题”      |
| 会议时间为空    | 提示“请选择会议时间”      |
| 会议纪要为空    | 提示“请填写会议纪要”      |
| 外部人员输入为空格 | 不生成标签            |
| 外部人员名称重复  | 保留一条，不重复保存       |
| 附件格式不支持   | 阻止加入上传列表并提示支持格式  |
| 单个附件上传失败  | 标记失败文件，允许删除后重新选择 |
| 新增接口失败    | 保留弹窗数据并提示失败原因    |
| 列表加载失败    | 显示加载失败状态和重试入口    |
| 附件下载失败    | 提示“附件下载失败，请稍后重试” |

## 13. 非功能要求

### 13.1 性能

* 首次进入会议纪要 Tab 时按需加载列表。
* 首次默认加载最近 20 条记录，滚动或分页加载更多。
* 列表接口响应时间目标不超过 2 秒。
* 附件不得以 Base64 形式直接存储在会议记录中。

### 13.2 安全

* 所有接口必须校验当前用户的项目访问权限。
* 文件下载地址必须进行权限校验，不得使用永久公开链接。
* 会议纪要正文按纯文本或安全富文本方式渲染，防止 XSS。
* 服务端必须再次校验附件扩展名、MIME 类型和文件大小。

### 13.3 可用性

* 表单控件支持键盘操作。
* 外部人员按 Enter 后应立即生成标签。
* 展开/收起按钮具备明确文字，不仅依赖图标表达状态。
* 右侧窄面板中，参会人和附件允许换行，但标签名称不得被拆字换行。

## 15. 验收标准

### AC-01 Tab 位置

项目详情页右侧显示“会议纪要”Tab，位于“合同记录”右侧。

### AC-02 时间流与排序

会议记录使用纵向时间流展示，并严格按照会议时间倒序排列。

### AC-03 列表样式

会议记录不使用外层卡片色块，相邻记录间距为 30px，会议时间显示在会议主题下方。

### AC-04 新增入口

会议纪要 Tab 右上角显示“新增记录”，点击后打开新增弹窗。

### AC-05 会议时间

会议时间使用日期时间选择控件，分钟只能选择 `00` 或 `30`。

### AC-06 内部参会人

内部参会人支持从在职员工中搜索并多选。

### AC-07 外部参会人

输入外部人员姓名并按 Enter 后生成标签，可以继续输入下一位，且不显示下拉列表。

### AC-08 长纪要折叠

会议纪要超过 10 行时显示“展开”，展开后显示完整内容并可收起；未超过 10 行时不显示按钮。

### AC-09 会议录音

会议录音支持多音频附件上传，上传列表不显示播放、预览、开始上传或圆形进度操作按钮。

### AC-10 会议资料

会议资料支持多附件上传，上传列表不显示播放、预览、开始上传或圆形进度操作按钮。

### AC-11 附件展示

列表中的“会议录音”和“会议资料”文字不换行，附件可正常下载。

### AC-12 提交

必填字段完整时可成功新增会议记录，新记录按照会议时间插入正确位置。

### AC-13 取消

点击取消不新增记录，再次打开弹窗时不保留上次未提交的数据。

### AC-14 空状态

项目没有会议记录时显示“暂无会议纪要”。

## 16. 测试建议

1. 验证会议时间仅提供整点和半点选项。
2. 验证内部员工搜索、多选、清空及离职员工过滤。
3. 连续输入多个外部人员，验证 Enter 生成标签且无下拉列表。
4. 验证空格、重复外部人员和失焦保存场景。
5. 分别上传单个和多个音频、文档、图片及压缩包。
6. 验证不支持的附件格式被正确拦截。
7. 验证上传列表不出现播放、开始上传或圆形进度操作按钮。
8. 验证会议记录按照会议时间倒序排列。
9. 使用不足 10 行、恰好 10 行和超过 10 行的纪要验证折叠逻辑。
10. 验证展开或收起一条记录不会影响其他记录。
11. 验证无录音、无资料、无参会人的记录展示。
12. 验证右侧窄面板中参会人、附件和长文本不会撑破布局。
13. 验证无权限用户无法查看或下载其他项目的会议数据。

## 17. 实施说明

当前前端原型使用页面状态模拟会议记录和附件，刷新页面后恢复默认示例数据。正式开发需要完成以下工作：

1. 新增会议记录、参会人、附件数据表。
2. 接入项目权限和员工管理数据。
3. 接入对象存储或现有文件服务。
4. 接入会议列表、新增和附件下载接口。
5. 补充接口异常、加载状态、分页及重试处理。
6. 完成单元测试、组件测试和接口联调。
