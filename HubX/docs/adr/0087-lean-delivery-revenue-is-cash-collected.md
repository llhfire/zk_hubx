# 0087 精益交付收入按回款口径（收付实现），不做完工百分比法

移植稿内财务模型文档写「权责发生制 / 完工百分比法确认收入」，mock 数据实际用的是收款阶梯，两套口径并存且总额矛盾（合同 205000 vs 阶梯总额 307500）。选回款口径：actualRevenue = 合同域 collectionRecords 累计，趋势图双线展示 paymentPlans 应收基线 vs 实际回款。理由：数据有实体来源（回款记录）可直接派生；完工百分比需要「完工进度」这个本身无来源的输入，且对外包公司管理现金流而言，落袋口径比确认口径更直接。**复审补丁：回款口径只用于 WIP/现金流展示，不做健康判定**--回款节奏后置会让交付前期利润率必然为负，健康灯/气泡图纵轴改用全周期口径（有效标的额 vs EAC）。完工百分比法标注为未来演进，不实现。
