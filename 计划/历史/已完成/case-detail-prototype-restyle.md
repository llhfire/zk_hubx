## 原型结构速记（6 Tab）

1. 概览看板：10 态生命周期轨迹（含补充合同履约标记+多协议经营提示）+ 有效标的额演进脉络卡（1主+N补+合并基准）+ 四维健康度卡（利润率达成/EAC vs 预算帽/WIP/商务上限）+ 双口径财务全景 + 成本收入趋势图（含收款穿透）+ 利润率波动趋势（含归因）+ 成本结构饼图（已发/预发切换）+ 成本构成 EAC 差异表 + 堆叠面积成本增长图 + 敏感性模拟器（盈亏平衡/底线价/安全边际 + scope/target 滑杆）
2. 工时评估：主合同+补充协议分块（归属合同/岗位/人天/成本日薪/报价日单价/成本小计/报价小计/状态）
3. 成本归集：5 分类卡 + Forecast 独立分区清单 + Actual 流水明细（写入通道列）
4. 主合同与补充协议：1主多补卡片（含生效影响提示）
5. 报价单版本池：主报价+补充报价卡片 + 行级明细
6. 项目决算：FTE 效能/复用节约/最终毛利 + 根因分析表

顶栏：CASE 编号 + 健康徽标 + 关联计数徽标 + 导出经营简报/打印/管理参数设置。
