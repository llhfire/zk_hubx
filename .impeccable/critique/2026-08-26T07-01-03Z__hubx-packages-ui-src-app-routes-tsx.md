# ZK HubX 全页面风格与一致性检查

> 检查日期：2026-08-26  
> 风格基准：`/leads/my`（我的线索）与 `/leads/:id`（线索详情）  
> 覆盖：静态扫描 88 个已注册页面组件；浏览器检查 25 个不同路由，覆盖列表、详情、工作台、看板和系统配置页。

## 总体结论

当前界面已有统一侧栏、顶栏、24px 内容边距和 Arco 组件底座，但页面级规范未形成。各模块更像在同一外壳中独立演进：标题使用 18/20/24/28px 四套尺度，内容宽度、筛选区、卡片密度和详情返回方式不一致。**设计健康度 5.1/10，设计特异性 4/10**，应先统一页面壳层，再逐域整理局部组件。

## 基准页规范

| 项目 | 建议统一值 |
|---|---|
| 页面外边距 | 24px；模块纵向间距 16px |
| 列表页 | 单主卡片：一级页签 → 快捷筛选 → 筛选栏 → 表格；正文 14px，辅助信息 12px |
| 详情页 | 顶部控制卡；实体名 18px/600；状态标签；右侧 28px 高小按钮；下接指标卡和 70:30 主辅分栏 |
| 卡片 | 白底、细边框、默认圆角，不使用重阴影和 3–4px 彩色侧边条 |
| 面包屑 | 一级列表不展示；二级配置、详情、编辑页展示“模块 / 列表 / 当前对象”，14px，底部间距 12px |
| 标题层级 | 页面标题 20px/600；详情实体名 18px/600；卡片标题 16px/600；禁止同级页面出现 24/28px 标题 |
| 内容宽度 | 默认随主内容区铺满；长表单/阅读页可限宽 1200px，禁止孤立的 960px 页面宽度 |

线索页提供了合适的密度和卡片节奏，但它本身没有正式面包屑。面包屑应作为补充的全局规则，不能照搬当前“各页自行返回”的做法。

## 主要问题与优先级

### P0：先解除阻断

1. `/contracts/:id` 稳定触发 `Rendered more hooks than during the previous render`，详情页无法进入，视觉整改前必须修复 `ContractDetail.tsx` 的条件 Hook。
2. 页面切换时会重复堆叠多条合同通知 Toast，持续遮挡页头和中部内容。应只在真实新事件发生时提示，并合并同类通知。

### P1：建立统一页面壳层

1. 88 个路由页面中仅 `/finance/contract-cost/:contractId` 使用面包屑；18 个详情/编辑页各自实现“返回”，层级语义不统一。
2. 34 个页面没有可识别的页面标题。客户、合同、项目、日报、审批、系统管理等列表页分别以页签、按钮或卡片内容代替标题。
3. 标题尺度分裂：线索详情 18px，工作台/报价 20px，客户/员工/差旅 24px，回款及精益交付看板 28px。
4. 宽度与留白不一：智能会议固定约 960px 居中；业务单列表和差旅列表存在额外内边距；多数页面则使用全宽画布。
5. 列表结构不一：部分页面缺页头和筛选分组，部分把一级标题做成 Tab，部分将操作按钮游离在卡片外。

### P2：收敛局部表现

1. 35 个路由页面含 20 处以上内联样式，造成字号、颜色、间距难以批量维护。
2. 自动检测发现 15 项警告，其中 13 项为 3–4px 彩色侧边条，集中在回款、员工详情和线索财务组件；另有 2 项文档预览字体例外。
3. 财务、差旅和精益交付看板大量使用独立 KPI 样式；精益交付还显示 `¥NaN`，破坏管理视图可信度。
4. 图标操作、文字操作和危险操作的排序、按钮尺寸、Tooltip 使用不一致；应复用线索列表的“小图标 + Tooltip”模式。

## 分域判断

| 页面域 | 一致性 | 重点整改 |
|---|---|---|
| 线索、客户、项目 | 较接近基准 | 补页面标题规则、详情面包屑，统一 18px 实体页头 |
| 报价、合同、回款 | 偏差大 | 先修合同详情；回款 28px 标题和侧边条降级；统一列表壳层 |
| 日报、交付 | 中等 | 日报列表补标题与层级；项目详情继续沿用线索详情节奏 |
| 财务、差旅、精益交付 | 偏差大 | 统一 KPI、颜色与内容起点；移除硬编码和重复内边距 |
| 人资、审批、系统 | 中等偏低 | 多数页面缺标题/面包屑；员工详情 24px 降为 18px |
| 资产、售后、供应商、知识库 | 中等 | 建立统一“摘要指标 + 主卡片”模板，补明确页头 |
| 智能会议 | 独立风格 | 取消 960px 孤岛式宽度，按全局画布或 1200px 阅读页规范处理 |

## 推荐整改顺序

1. 修合同详情和全局重复通知。
2. 新建共享 `PageShell`、`PageHeader`、`PageBreadcrumb`、`FilterBar`，先迁移全部一级列表页。
3. 以线索详情为模板迁移客户、项目、员工、合同、差旅、业务单详情。
4. 统一财务/差旅/精益交付看板的 20px 页头、KPI 卡片和颜色语义。
5. 将高频内联样式沉淀为 token/CSS，并补桌面 1440px 与窄屏回归检查。

## 检查记录

- 设计评估与自动检测分开进行；自动检测仅在人工结论完成后运行一次。
- 浏览器使用真实 α 页面截图和计算样式，没有注入覆盖层，也未修改运行时 DOM。
- 当前会话没有多评审代理能力，本次为单上下文检查；结论应在首批页面迁移后再复核。
- 本轮只检查并记录问题，未修改生产页面样式。
