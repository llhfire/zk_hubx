# 0088 保留 CASE- 独立编号，精益交付为主术语表的第四视角（财务交付视角）

`HubX/CONTEXT.md` 原定义「线索、项目、合同是同一笔业务的三视角，不另建业务单」。精益交付移植稿建了独立编号 `CASE-YYYY-MM-DD-序号` 的平行实体，与该决策直接冲突。本决策修订而非拆除：保留 CASE- 独立编号与精益交付页面群，主术语表业务单概念增补**财务交付视角**（第四视角）。理由：管理层需要跨业务的财务全景入口（EAC/利润/WIP 预警），三视角页面各自只看局部；派生化之后 Case 不持有业务明细事实，只是 (报价, 合同, 成本流水) 的聚合视图对象，不会产生第二事实源。**复审修正案：Case 承认为轻实体**--除聚合视图外持有管理参数（targetMargin/budgetCap/commercialCap，无第二个候选主人）与自有 10 态状态机；「协商中」「催款中」在报价/合同/项目域均无可派生的对应状态，硬凑映射表比自持状态更脆弱。代价：全系统存在四个业务编号视角（线索/项目/合同/业务单），Case 编号是唯一一个不为写入服务的编号。
