# 01 · 线索弹层收口

文件：`packages/ui/src/app/leads/LeadTransferPopover.tsx` + 新建 `LeadTransferPopover.css`

## 收掉的 5 处内联视觉样式

严格门禁的 `visualInlineStyle` 只统计 `app/pages/` 之外的节点（leads 是上一场新扩的扫描范围），
这条债就挂在这一个文件的 4 个指纹、5 次出现上：

| 位置 | 原来 | 现在 |
|---|---|---|
| 内容根节点 | `style={{ fontSize: 'var(--text-xs)' }}` | `.lead-transfer-popover` |
| 摘要行 | `style={{ marginBottom: 8, color: 'var(--color-text-3)' }}` | `.lead-transfer-popover__meta`（`--space-2` + `--ds-text-tertiary`） |
| 空态 | `style={{ color: 'var(--color-text-4)', textAlign: 'center', padding: 12 }}` | 删掉，交给 `DataTable` 的 `emptyDescription` |
| 触发器 | `style={{ fontSize: 'var(--text-xs)', height: 'auto', padding: 0, display: 'inline-flex', flexDirection: 'column', gap: 2, textAlign: 'left' }}` | `.lead-transfer-popover__trigger` |
| 预算行 | `style={{ whiteSpace: 'nowrap', color: 'var(--color-text-1)' }}` | `.lead-transfer-popover__trigger-budget`（`--ds-text-primary`） |

文本色统一换成 `--ds-text-*` 别名（`--ds-text-tertiary` / `--ds-text-primary`），不再直写
`--color-text-N` —— tokens.css 里那两个别名就是为这件事存在的。

## 顺手修的三处

1. **空态重复实现**：原来自己拼了一段居中灰字。改成 `DataTable` 的 `emptyDescription="暂无流转记录"`，
   空态回到 `EmptyState` 唯一实现；顺手把「有记录 / 无记录」的分支整个删掉，表格常驻，少一次条件渲染。
2. **金额不走唯一入口**：原来 `budget == null ? '—' : \`¥${budget.toLocaleString()}\``。改成 `<MoneyText value={budget} />`：
   占位符、千分位、数字字体都由 `MoneyText` 给，整数输出与原来一致（`¥1,200,000`）。
3. **加载中就宣告「暂无流转记录」**：`records === null` 时按钮已打开但请求未回，原来自定义空态会先说没记录。
   现在 `loading={records === null}`，用表格自身的 loading，说完再判空。
