# 实现计划：线索·项目·合同统一视图

> 2026-08-18 · 不写代码的计划稿  
> PRD：`文档/PRD/PRD-线索项目合同统一视图.md`（v1.1）  
> 领域：`HubX/CONTEXT.md` + ADR `0066`–`0075`（报价域 `0001`–`0065` 不推翻）

三视角怎么互相看见、何时立项、何时退回、合同作废/线索终止对项目的影响。不另建「业务单」菜单。

## 0. 已拍板（实现时不得改回去）

- 已确认 ≠ 签约；合同仍经向导，不自动插入。
- 未确认项目在**签约开启**时产生：线索进入合同洽谈/已签单，或未作废主合同创建（草稿也算）。合同批准只把已指派项目打成进行中。
- 管理员确认未确认项目并指定产品经理 → 未开始。之后仍可改指。
- 退回线索：未确认，或未开始且无未作废主合同。进行中不能退。
- 主合同作废 → 进行中项目搁置；新主合同批准再开工。补充合同作废不搁置。
- 线索终止不停止交付。
- 线索/合同/项目状态机沿用现网。
- 报价是独立对象，三视角只读引用。
- 线索详情合同/回款入口一直在，主合同草稿即可引用。
- 日报只在项目写；成本合同可看、线索不看。
- 内部项目无线索/客户/合同，不进统一视图，仍做成本。
- 线索客户与合同甲方创建后各改各的，对不上黄灯。

## 1. 明确不做

- 重写三套状态机。
- 为内部项目补销售线索。
- 进行中项目退回线索。
- 线索终止自动搁置项目。

## 2. 阶段

### U1. 立项触发改回签约开启

阶段 3 把 `spawnUnconfirmedProject` 挂在 `approvedAt` 上，按 ADR 0067 拆开：

- 线索进入合同洽谈/已签单，或主合同创建（草稿）→ spawn（尚无项目时）。
- `approvedAt` 只对已指派的未开始/搁置项目走 `startDelivery`。
- 未确认项目不在批准时才第一次出现。

**验收**：线索打成合同洽谈、尚无合同，管理员队列里出现未确认项目。

> 详细开发计划（实施步骤 / 文件清单 / 测试用例设计 / 边界决策）：`计划/当前/unified-view-u1-dev-plan.md`。

### U2. 退回线索

- 管理员对未确认，或未开始且无未作废主合同，可退回。
- 关闭项目；线索从洽谈/已签单改回方案报价。
- 有未作废主合同或进行中 → 拒绝。

**验收**：点错洽谈能退回且不会立刻再 spawn；有合同草稿时不能退。

### U3. 主合同作废 ↔ 项目搁置

- 主合同作废：进行中 → 搁置。
- 新主合同批准：搁置/未开始 → 进行中（已有指派）。
- 补充合同作废不动项目状态。

**验收**：作废主合同后面板变成搁置，日报还在；再批准后回到进行中。

> 详细开发计划：`计划/当前/unified-view-u3-dev-plan.md`。

### U4. 线索侧合同/回款入口

- Tab 一直在；无合同空态；主合同草稿即可只读引用。
- 回款写入仍在合同；批准前按阶段 3 规则决定能不能登记。
- 不展示日报；不展示成本核算。

**验收**：向导刚建出草稿，线索详情能看见该合同。

> 详细开发计划：`计划/当前/unified-view-u4-dev-plan.md`。

### U5. 改指产品经理 + 客户/甲方黄灯

- 未开始/进行中管理员可改当前产品经理。
- 列表按当前产品经理过滤。
- 线索客户 ≠ 合同甲方 → 黄灯，不自动回写。

### U6. 内部项目

> 详细开发计划（U5 与 U6 合并）：`计划/当前/unified-view-u5-u6-dev-plan.md`。

- 无线索、无客户、无合同的项目不进业务单，不做三视角 Tab。
- 成本统计照常；不做成本 vs 合同额提醒。

## 3. 顺序

`U1 → U2 → U3 → U4 ∥ U5 → U6`

U1 必须先于 U2（退回依赖正确的 spawn 条件）。

## 4. 测试

- `caseUtils`：洽谈 spawn、批准不重复 spawn、退回条件、作废搁置、再批准开工。
- 全量 vitest 不新增基线债；`npm run build`。
- 人工：洽谈→未确认→指派→批准开工；退回；作废搁置；线索终止交付仍在。
