# 01 · 组件库四层

## 问题

`/ui-library` 原来是 `UiComponentLibraryPage.tsx` 一个 1231 行文件，四个页签的实测内容：

| 页签 | 实样数 | 问题 |
|---|---:|---|
| 基础 UI | 2 | 原子组件被搬到了「模块组件」，这层空心 |
| 模块组件 | 45 | 六个分组函数存在，但页面上一张卡接一张卡，没有二级导航 |
| 页面框架 | 0 | 三张纯文字卡，列的是组件名，一个渲染都没有 |
| 业务样板 | 1 | 只有线索列表 |

## 新结构

```
app/pages/ui-library/
├── UiComponentLibraryPage.tsx   页签壳（~60 行）
├── data.ts                      目录行（foundationRows / moduleRows）
├── useLibraryTabs.ts            页签位置写进 hash
├── demos/                       6 组实样 + fixtures.ts 共享假数据
└── panels/
    ├── FoundationPanel.tsx      基础 UI
    ├── ModulesPanel.tsx         模块组件（6 个二级页签）
    ├── FrameworksPanel.tsx      页面框架 + frameworks/ 4 个骨架
    └── PatternsPanel.tsx        业务样板 + patterns/ 4 个切片
```

四层定义（写进页面头部说明与规范）：

| 层 | 装什么 | 二级导航 |
|---|---|---|
| 基础 UI | 单一值 / 单一输入，无业务语义（金额、状态、等级、日期、标识、图标、输入、选择、上传） | 值展示 / 录入控件 / 基础层速查 |
| 模块组件 | 由原子组合出的可复用块 | 容器与导航 5 / 表格与展示 6 / 反馈与确认 3 / 业务区块 15 / 主辅布局 1 / 组件目录 53 |
| 页面框架 | 可直接看的页面骨架 | 列表页 5 槽 / 长流程详情 6 槽 / 工作台 4 槽 / 配置设置页 4 槽 |
| 业务样板 | 真实页面切片 + 复制边界 | 线索列表 / 项目详情 / 合同详情 / 财务统计 |

页签位置写进 hash（`#modules/business`、`#frameworks/detail`、`#patterns/contract`），刷新与分享都落回同一处。

## 页面框架：骨架必须能看

四个骨架都用假数据搭、虚线框 + 编号槽位标注，并明确写「骨架不是页面：复制假数据等于制造第二份实现」，
每个骨架末尾给出真实页面参照路径。

施工中发现并修正了骨架自身的一个错：最初把 `DetailHeader`（返回 + 标题 + 状态）和
`ProcessOverview`（身份 + 标签 + 操作 + 流程条）**叠了两层**，属重复外壳。真实详情页 12 处
（项目 / 线索 / 合同 / 客户 / 报价 / 宿舍 / 员工 / 案例…）统一只用 `ProcessOverview`；
`DetailHeader` 是没有阶段流程条时的轻变体（真实用例 `/finance/contract-cost/:id`）。
骨架已改为 6 槽并写明这条，两个样板同步改。

## 业务样板：必须写清复制边界

每个样板下面挂一个 `CopyNotes`，左「可以复制的」右「不要复制的」。例如项目详情：
可以抄「面包屑 → 页头 → 流程条 → 指标 → 主辅区」的顺序与「辅区放回款/进展」的职责划分；
不要抄 5 个阶段命名、回款比例算法、里程碑口径。

## 门禁为了拆文件而修

`scripts/check-design-system.mjs` 的 `findComponentsWithoutDemo()` 原来只读
`UiComponentLibraryPage.tsx` 一个文件判断「每个导出是否有实样」。拆成目录后，
它会误报 54 个导出缺实样（`libraryMissingDemo: 54`，门禁直接失败）。已改为扫整个
`ui-library/` 目录下的 `.tsx`。这一条以后谁再拆文件都要靠它。

## 页面文案去英文

分组标题不再挂 `primitives/`、`data-display/`、`forms/` 等目录后缀；页签「值 primitives / 录入 controls」
改成「值展示 / 录入控件」；`toolbar / actions / caption`、`quiet`、`bare`、`compact / closable`
等说明词改中文。**保留**组件名（`MoneyText`、`DataTable`）、属性值（`size=small`、`tone=success`、
`mode=datetime`、`template=2-1-1`）和 `@/design-system` —— 这些要照着写代码。
